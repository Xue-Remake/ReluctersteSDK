# 02 · 实体映射

**目标**：把 POCO 正确映射到表：选表名、列名、主键（含复合主键），知道哪些属性会入库、哪些类型不支持。

---

## 1. 四个特性

```csharp
using ReluctersteSDK.Sqlite;

[DbTable("players")]                 // 表名；不写或为空时用类名
public sealed class PlayerRow
{
    [DbKey("id")]          public long Id { get; set; }
    [DbColumn("name")]     public string Name { get; set; } = "";
    [DbColumn]             public int Score { get; set; }
    [DbIgnore]             public string Cache { get; set; } = "";
}
```

| 特性 | 目标 | 说明 |
|---|---|---|
| `[DbTable("name")]` | class | 不写 / 为空时用**类名**（不是小写、不是复数） |
| `[DbKey("id")]` | property | 主键；可标多个 → 复合主键 |
| `[DbColumn("name")]` | property | 普通列 |
| `[DbIgnore]` | property | 显式排除 |

### 列名解析优先级

```
[DbColumn.Name] > [DbKey.Name] > 属性名
```

不写参数时直接用属性名。

## 2. 哪些属性会入库

```csharp
type.GetProperties(BindingFlags.Public | BindingFlags.Instance)
    .Where(p => p.CanRead && p.CanWrite)
    .Where(p => p.GetCustomAttribute<DbIgnoreAttribute>() == null)
    // 然后只保留带 [DbKey] 或 [DbColumn] 的
```

三条规则：

1. `[DbKey]` 属性**一定**入库；
2. `[DbColumn]` 属性入库；
3. 两者都没有的属性**默认不入库**，不需要 `[DbIgnore]`。

硬性要求：

- 属性必须是 `public`，且同时有 `get` / `set`；
- 一个映射都没有时抛 `InvalidOperationException`；
- 映射结果按类型缓存在 `ConcurrentDictionary`，**每种类型只反射一次**，运行期改特性不会生效。

---

## 3. 复合主键

```csharp
[DbTable("inventory")]
public sealed class InventoryRow
{
    [DbKey("player_id")] public long PlayerId { get; set; }
    [DbKey("item_id")]   public long ItemId { get; set; }
    [DbColumn("count")]  public int Count { get; set; }
}
```

主键顺序 = **属性声明顺序**：

```csharp
await db.GetByKeyAsync<InventoryRow>(1001, 2002);   // player_id=1001, item_id=2002 ✅
await db.GetByKeyAsync<InventoryRow>(2002, 1001);   // ❌ 顺序反了
await db.DeleteByKeyAsync<InventoryRow>(1001, 2002);
```

`GetByKeyAsync` / `DeleteByKeyAsync` 会校验键数量，不匹配抛 `ArgumentException`。

建表生成的 SQL：

```sql
CREATE TABLE IF NOT EXISTS "inventory" (
    "player_id" INTEGER NOT NULL,
    "item_id" INTEGER NOT NULL,
    "count" INTEGER NOT NULL,
    PRIMARY KEY ("player_id", "item_id")
);
```

## 4. 可空性

`IsNullable` 规则：

| 属性类型 | 可空 |
|---|---|
| 引用类型（`string`、数组等） | ✅ |
| `Nullable<T>`（`int?`、`DateTime?`） | ✅ |
| 其它值类型（`int`、`bool`、`DateTime`） | ❌ |

建表时：

- 键列**总是** `NOT NULL`；
- 非键列在 `!IsNullable` 时加 `NOT NULL`；
- `Nullable<T>` 允许数据库 `NULL`，读回 `DBNull` → `null`。

```csharp
[DbColumn("note")] public string? Note { get; set; }      // TEXT，可空
[DbColumn("level")] public int? Level { get; set; }       // INTEGER，可空
[DbColumn("score")] public int Score { get; set; }        // INTEGER NOT NULL
```

## 5. 类型映射

| .NET 类型 | SQLite 类型 | 存储形式 |
|---|---|---|
| `byte` `sbyte` `short` `ushort` `int` `uint` `long` `ulong` `bool` | `INTEGER` | `bool` → 0/1 |
| 任意 `enum` | `INTEGER` | 底层整数值 |
| `float` `double` `decimal` | `REAL` | |
| `string` | `TEXT` | |
| `DateTime` | `TEXT` | `"O"` 往返格式（含 `Kind`） |
| `DateTimeOffset` | `TEXT` | `"O"` |
| `Guid` | `TEXT` | `ToString()` |
| `byte[]` | `BLOB` | |
| `Nullable<T>` | 同 `T` | `DBNull` ↔ `null` |

以下类型会在**建表阶段**直接抛 `NotSupportedException`：

- 自定义类 / 结构体；
- `List<T>`、`Dictionary<,>`；
- `char`、`TimeSpan` 等未列出的类型。

需要存复杂对象时，自己序列化成 `string` / `byte[]`，或拆成多列。

---

## 6. 表名与类名

```csharp
[DbTable]                       // 表名 = 类名
public class Player { }

[DbTable("t_player")]           // 显式表名
public class Player { }

// 不加特性：表名同样是类名
public class Player { }
```

表名、列名会被 `SqliteUtils.QuoteIdentifier` 加双引号并转义内部引号，因此可以包含空格或保留字。

## 7. 完整示例：复合主键的库存表

```csharp
using ReluctersteSDK.Sqlite;

[DbTable("inventory")]
public sealed class InventoryRow
{
    [DbKey("player_id")] public long PlayerId { get; set; }
    [DbKey("item_id")]   public long ItemId { get; set; }
    [DbColumn("count")]  public int Count { get; set; }
    [DbColumn("updated")]public DateTime Updated { get; set; }

    public override string ToString() => $"{PlayerId}:{ItemId} x{Count}";
}

await using var db = new SqliteDataBase(folder, "game.db");
await db.EnsureInitializedAsync();
await db.EnsureTableAsync<InventoryRow>();

await db.UpsertAsync(new InventoryRow
{
    PlayerId = 1001,
    ItemId = 2002,
    Count = 3,
    Updated = DateTime.UtcNow
});

// 主键顺序：player_id, item_id
InventoryRow? row = await db.GetByKeyAsync<InventoryRow>(1001, 2002);
Console.WriteLine(row);   // 1001:2002 x3

await db.DeleteByKeyAsync<InventoryRow>(1001, 2002);
```

## 8. 已知限制

| 限制 | 说明 |
|---|---|
| 只支持基础类型 | 自定义类 / 集合 / `char` / `TimeSpan` 不支持 |
| 必须可读写 | 只有 `get` 的属性静默跳过；`private` 属性不扫描 |
| 映射缓存 | 同进程内类型映射不可变 |
| 无继承分层 | 只扫描声明类型自身的 `public` 实例属性 |
| 表名/类名重命名 | 没有自动迁移；旧表不会自动改名 |
| 特性名不转义 | 表名/列名来自特性，视为静态可信 |
