# 05 · 纯行模式（RowMod）

**目标**：不定义实体类，直接按“表名 + 行字典”建表、插入、查询、更新、删除。

适合：schema 运行时才知道、一次性脚本、导入导出、原型验证。

---

## 1. 入口

```csharp
using ReluctersteSDK.Sqlite;
using ReluctersteSDK.Sqlite.RowMod;

await using var db = new SqliteDataBase(folder, "rowmod.db");
await db.EnsureInitializedAsync();

await using var ctx = new RowDbContext(db);
RowTable users = ctx["users"];
```

`RowDbContext.DisposeAsync()` 会**连带释放** `SqliteDataBase`：

```csharp
await using var ctx = new RowDbContext(db);   // ✅ 只释放 ctx
```

不要同时对 `db` 和 `ctx` 使用 `await using`。

---

## 2. 建表

```csharp
await users.CreateTableIfNotExistsAsync(
    ("id",    "INTEGER PRIMARY KEY AUTOINCREMENT"),
    ("name",  "TEXT NOT NULL"),
    ("age",   "INTEGER"),
    ("email", "TEXT"));
```

- 列类型是**原始 SQLite 类型字符串**，直接拼进 `CREATE TABLE`；
- 只接受代码里写死的值；
- 表名、列名会被加双引号转义。

生成：

```sql
CREATE TABLE IF NOT EXISTS "users" (
    "id" INTEGER PRIMARY KEY AUTOINCREMENT,
    "name" TEXT NOT NULL,
    "age" INTEGER,
    "email" TEXT
);
```

---

## 3. 插入

### 单行

```csharp
await users.AddAsync(new Row
{
    ["name"] = "Alice",
    ["age"] = 25,
    ["email"] = "alice@example.com"
});
```

`Row` 是大小写不敏感的列字典：

```csharp
var row = new Row { ["Name"] = "Alice", ["age"] = 25 };
Console.WriteLine(row["name"]);   // Alice
Console.WriteLine(row["missing"]); // null，不抛异常
```

### 批量（单事务）

```csharp
Row[] batch =
{
    new Row { ["name"] = "Bob",   ["age"] = 31 },
    new Row { ["name"] = "Carol", ["age"] = 28 },
    new Row { ["name"] = "Dave",  ["age"] = 42 }
};

await users.AddRangeAsync(batch);
```

`AddRangeAsync` 在一个事务里逐条插入，比循环 `AddAsync` 快很多（少一次连接/锁开销），失败整体回滚。

> 各行的列集合应一致；缺列的行会生成不同 SQL，但仍在同一事务内。

---

## 4. 查询

```csharp
// 全表
List<Row> all = await users.ToListAsync();
long count = await users.CountAsync();

// 单条件
Row? alice = await users
    .Where(r => r.Get<string>("name") == "Alice")
    .FirstOrDefaultAsync();

// 多条件 + 排序 + 分页
List<Row> page = await users
    .Where(r => r.Get<int>("age") >= 18 && r.Get<string>("email")!.Contains("example"))
    .OrderByDescending("age")
    .Skip(10)
    .Take(5)
    .ToListAsync();

// 只取部分列
List<Row> names = await users
    .Select("name")
    .ToListAsync();
```

### `Row.Get<T>` 与索引器

```csharp
Row row = all[0];

int age = row.Get<int>("age");        // 走类型转换
string? name = row.Get<string>("name");

object? raw = row["age"];             // 原始值
```

`Get<T>` 的转换规则与类型映射一致：枚举按整数、`bool` 按 0/1、`DateTime` 按 `"O"` 解析。值缺失或 `DBNull` 返回 `default`。

---

## 5. 更新与删除

```csharp
// 条件更新：只改给定列
int updated = await users
    .Where(r => r.Get<string>("name") == "Alice")
    .UpdateAsync(new Row { ["age"] = 26 });

// 条件删除
int deleted = await users
    .Where(r => r.Get<int>("age") < 18)
    .DeleteAsync();
```

`UpdateAsync(Row)`：

- `updateData` 里的列会写进 `SET`；
- 没给的列**保持不变**（与特性映射的 `UpdateAsync<T>` 不同）；
- 没有 `WHERE` 时更新整表。

---

## 6. 表达式支持范围

`Where(Expression<Func<Row,bool>>)` 只翻译：

| 类别 | 支持 |
|---|---|
| 比较 | `==` `!=` `>` `>=` `<` `<=` |
| 逻辑 | `&&` `\|\|` `!` |
| 取列 | `r.Get<T>("col")`、`r["col"]` |
| 字符串 | `string.Contains("x")` → `LIKE '%x%'` |
| 常量 / 变量 | 作为参数绑定 |

**不支持**：`in`、`StartsWith` / `EndsWith`、排序 lambda、`OR` 分组括号、其它方法调用、字符串插值。

不认识的子表达式会 `Compile()` 后在内存求值，结果作为参数——能跑，但**不参与 SQL 过滤**，等于先全表读再筛。复杂查询请直接写 SQL。

```csharp
// ✅ 推荐
await users.Where(r => r.Get<int>("age") >= 18 && r.Get<string>("name")!.Contains("A")).ToListAsync();

// ⚠️ StartsWith 不被翻译，行为取决于求值方式；改用 Contains 或原生 SQL
```

## 7. 完整示例

```csharp
using ReluctersteSDK.Sqlite;
using ReluctersteSDK.Sqlite.RowMod;

await using var db = new SqliteDataBase(folder, "rowmod_demo.db");
await db.EnsureInitializedAsync();

await using var ctx = new RowDbContext(db);
RowTable users = ctx["users"];

await users.CreateTableIfNotExistsAsync(
    ("id",        "INTEGER PRIMARY KEY AUTOINCREMENT"),
    ("name",      "TEXT NOT NULL"),
    ("age",       "INTEGER"),
    ("email",     "TEXT"),
    ("is_active", "INTEGER"));

await users.AddAsync(new Row
{
    ["name"] = "Alice",
    ["age"] = 25,
    ["email"] = "alice@example.com",
    ["is_active"] = 1
});

await users.AddRangeAsync(new[]
{
    new Row { ["name"] = "Bob",   ["age"] = 31, ["email"] = "bob@example.com",   ["is_active"] = 1 },
    new Row { ["name"] = "Carol", ["age"] = 17, ["email"] = "carol@example.com", ["is_active"] = 0 },
    new Row { ["name"] = "Dave",  ["age"] = 42, ["email"] = "dave@example.com",  ["is_active"] = 1 }
});

Console.WriteLine($"总数：{await users.CountAsync()}");

List<Row> adults = await users
    .Where(r => r.Get<int>("age") >= 18 && r.Get<int>("is_active") == 1)
    .OrderByDescending("age")
    .Take(10)
    .ToListAsync();

foreach (Row row in adults)
    Console.WriteLine($"{row.Get<string>("name")}\t{row.Get<int>("age")}");

await users
    .Where(r => r.Get<string>("name") == "Carol")
    .UpdateAsync(new Row { ["is_active"] = 1 });

int removed = await users
    .Where(r => r.Get<int>("age") >= 100)
    .DeleteAsync();

Console.WriteLine($"删除 {removed} 行");
```

## 8. 陷阱

| 陷阱 | 说明 |
|---|---|
| **`RowQuery` 是可变构建器** | 重复执行同一实例会累积 `WHERE`；`FirstOrDefaultAsync()` 会把 `LIMIT` 永久改成 1 |
| 列名不校验 | 表达式里的 `"age"` 拼错，要到 SQLite 执行时才报错 |
| `Row` 大小写不敏感，SQL 字符串不是 | `row["Name"]` 与 `row["name"]` 同列，但 `Where(r => r.Get<int>("Age")…)` 生成的 SQL 用 `"Age"` |
| 无 JOIN / 子查询 / 分组 | 复杂查询用 `db.QuerySqlAsync` |
| `UpdateAsync(Row)` 整列覆盖 | 只写给定列，未给的保持；不要传空 `Row`（直接返回 0） |
| `AddAsync` 空行 | `row.Count == 0` 返回 0，不发 SQL |
| `DisposeAsync` 连带释放 | 不要对 `db` 和 `ctx` 同时 `await using` |
| `Skip` 单独使用 | 生成 `LIMIT -1 OFFSET n`，依赖 SQLite 方言 |
