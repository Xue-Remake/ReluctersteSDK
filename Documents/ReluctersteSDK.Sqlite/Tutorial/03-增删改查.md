# 03 · 增删改查

**目标**：把特性映射模式的全部 CRUD 方法用一遍，知道条件、参数、排序、分页怎么写，以及 `Insert` / `Upsert` / `Update` 的差别。

---

## 1. 方法总表

| 方法 | 返回 | 说明 |
|---|---|---|
| `EnsureTableAsync<T>()` | `Task` | `CREATE TABLE IF NOT EXISTS`；`where T : new()` |
| `InsertAsync<T>(T entity)` | `Task<int>` | 插入，主键冲突抛异常 |
| `UpsertAsync<T>(T entity)` | `Task<int>` | 主键冲突则更新非键列 |
| `UpdateAsync<T>(T entity)` | `Task<int>` | 按主键更新**全部非键列** |
| `DeleteAsync<T>(T entity)` | `Task<int>` | 按实体主键删除 |
| `DeleteByKeyAsync<T>(params object?[] keys)` | `Task<int>` | 按键值删除 |
| `GetByKeyAsync<T>(params object?[] keys)` | `Task<T?>` | 找不到返回 `null` |
| `QueryAsync<T>(where, parameters, orderBy, limit)` | `Task<List<T>>` | 条件查询 |
| `GetAllAsync<T>()` | `Task<List<T>>` | 先确保表存在，再全表读取 |

当前 CRUD API **没有** `CancellationToken` 参数（`Microsoft.Data.Sqlite` 的命令本身支持取消，但这一层没有透出）。需要取消请用原生 SQL 或迁移上下文。

---

## 2. 插入

```csharp
await db.InsertAsync(new PlayerRow
{
    Id = 1,
    Name = "Alice",
    Score = 10,
    CreatedAt = DateTime.UtcNow
});
```

- 主键冲突会抛 `SqliteException`（`UNIQUE constraint failed`）；
- 所有列都写入，包括键；
- 返回受影响行数（通常 1）。

### 批量插入

特性映射模式**没有批量 API**，也没有公开事务。两条路：

```csharp
// 1) 循环 Insert：每次一条 SQL、一次连接、一次写锁
foreach (PlayerRow row in rows)
    await db.InsertAsync(row);

// 2) 自定义批量 SQL：手工拼多 VALUES，参数名自己编号
//    仍然走一次 ExecuteAsync（一次连接、一次写锁）
```

需要**单事务**批量插入时，用 RowMod 的 `RowTable.AddRangeAsync`（见 [05-纯行模式.md](05-纯行模式.md)），或在迁移上下文里执行 DML。特性映射模式没有对外的事务 API。

---

## 3. 查询单条

```csharp
PlayerRow? row = await db.GetByKeyAsync<PlayerRow>(1);

if (row is null)
    Console.WriteLine("不存在");
else
    Console.WriteLine($"{row.Name} / {row.Score}");
```

复合主键按声明顺序：

```csharp
InventoryRow? inv = await db.GetByKeyAsync<InventoryRow>(playerId: 1001, itemId: 2002);
```

实际签名是 `params object?[]`，所以上面不能用具名参数；写成：

```csharp
InventoryRow? inv = await db.GetByKeyAsync<InventoryRow>(1001, 2002);
```

---

## 4. 条件查询

```csharp
List<PlayerRow> rows = await db.QueryAsync<PlayerRow>(
    where: "score > @min AND name LIKE @prefix",
    parameters: new { min = 15, prefix = "A%" },
    orderBy: "score DESC, name ASC",
    limit: 10);
```

| 参数 | 规则 |
|---|---|
| `where` | 可带可不带 `WHERE` 前缀；**片段不转义**，只写死字符串 |
| `parameters` | 匿名对象 / 字典 / `KeyValuePair` 集合 / `SqliteParameter` 集合 |
| `orderBy` | 不含 `ORDER BY` 关键字；也是裸字符串 |
| `limit` | 生成 `LIMIT n` |

### 参数形状

```csharp
// 匿名对象
new { min = 15, prefix = "A%" }

// 字典
new Dictionary<string, object?>
{
    ["min"] = 15,
    ["prefix"] = "A%"
}

// KeyValuePair 集合
new[]
{
    new KeyValuePair<string, object?>("min", 15),
    new KeyValuePair<string, object?>("prefix", "A%")
}

// SqliteParameter 集合（需要 using Microsoft.Data.Sqlite）
new[] { new SqliteParameter("@min", 15) }
```

参数名不需要写 `@`，内部会补。值统一经 `SqliteTypeMapper.ToDbValue` 转换（枚举→整数、`bool`→0/1、`DateTime`→`"O"`）。

### 不要拼用户输入

```csharp
// ❌ 用户输入直接进 where
string where = $"name = '{userInput}'";
await db.QueryAsync<PlayerRow>(where);

// ✅ 值走参数
await db.QueryAsync<PlayerRow>(
    where: "name = @name",
    parameters: new { name = userInput });
```

`where` / `orderBy` 是**裸 SQL 片段**，库不会校验、不会转义。

## 5. 更新

### `UpdateAsync`：主键定位，覆盖全部非键列

```csharp
await db.UpdateAsync(new PlayerRow
{
    Id = 1,
    Name = "Alice",
    Score = 99,
    CreatedAt = DateTime.UtcNow
});
```

生成的 SQL 类似：

```sql
UPDATE "players"
SET "name" = @p0, "score" = @p1, "created_at" = @p2
WHERE "id" = @k0;
```

要点：

- 没给值的列会被写成该属性的当前值（`default` 或你传的值），**不是“保持不变”**；
- 只改一列请用原生 SQL：`UPDATE players SET score = @s WHERE id = @id`；
- 没有非键列时直接返回 0，不发 SQL。

### `UpsertAsync`：有则更新，无则插入

```csharp
await db.UpsertAsync(new PlayerRow
{
    Id = 2,
    Name = "Bob",
    Score = 55,
    CreatedAt = DateTime.UtcNow
});
```

生成：

```sql
INSERT INTO "players" ("id","name","score","created_at")
VALUES (@p0,@p1,@p2,@p3)
ON CONFLICT ("id") DO UPDATE SET
    "name" = excluded."name",
    "score" = excluded."score",
    "created_at" = excluded."created_at";
```

只有键列时退化为 `INSERT OR IGNORE`。

### 三者对比

| 场景 | 用哪个 |
|---|---|
| 明确是新增，冲突要报错 | `InsertAsync` |
| 不确定是否存在，存在就覆盖 | `UpsertAsync` |
| 确定存在，整行更新 | `UpdateAsync` |
| 只改一两列 | `ExecuteAsync` 写原生 SQL |

## 6. 删除

```csharp
// 按实体
PlayerRow row = new PlayerRow { Id = 1 };
await db.DeleteAsync(row);

// 按键
await db.DeleteByKeyAsync<PlayerRow>(1);

// 按条件（原生 SQL）
int removed = await db.ExecuteAsync(
    "DELETE FROM players WHERE score < @min",
    new { min = 0 });
```

`DeleteAsync` / `DeleteByKeyAsync` 只按主键删除，不支持条件；条件删除走 `ExecuteAsync`。

---

## 7. 全表读取

```csharp
List<PlayerRow> all = await db.GetAllAsync<PlayerRow>();
```

它等价于：

```csharp
await db.EnsureTableAsync<PlayerRow>();
List<PlayerRow> all = await db.QueryAsync<PlayerRow>();
```

`GetAllAsync` 会先建表（幂等），适合“第一次启动还没有表”的场景；其它查询方法不会自动建表。

---

## 8. 自定义投影

有时不需要完整实体：

```csharp
using Microsoft.Data.Sqlite;

var pairs = await db.QuerySqlAsync(
    "SELECT name, score FROM players WHERE score > @min ORDER BY score DESC",
    reader => (Name: reader.GetString(0), Score: reader.GetInt32(1)),
    new { min = 10 });

foreach (var pair in pairs)
    Console.WriteLine($"{pair.Name}: {pair.Score}");
```

`QuerySqlAsync` 的第二个参数是**行投影委托**，返回类型由你决定；SQL 完全自己负责。

---

## 9. 完整示例

```csharp
using ReluctersteSDK.Sqlite;

await using var db = new SqliteDataBase(folder, "crud.db");
await db.EnsureInitializedAsync();
await db.EnsureTableAsync<PlayerRow>();

// 插入
for (int i = 1; i <= 5; i++)
{
    await db.InsertAsync(new PlayerRow
    {
        Id = i,
        Name = $"Player{i}",
        Score = i * 10,
        CreatedAt = DateTime.UtcNow
    });
}

// 查询 Top 3
List<PlayerRow> top3 = await db.QueryAsync<PlayerRow>(
    orderBy: "score DESC",
    limit: 3);

// 更新
PlayerRow first = top3[0];
first.Score += 100;
await db.UpdateAsync(first);

// Upsert
await db.UpsertAsync(new PlayerRow
{
    Id = 99,
    Name = "Newcomer",
    Score = 5,
    CreatedAt = DateTime.UtcNow
});

// 删除
await db.DeleteByKeyAsync<PlayerRow>(99);

Console.WriteLine((await db.GetAllAsync<PlayerRow>()).Count);   // 5
```

## 10. 常见异常

| 异常 | 场景 |
|---|---|
| `InvalidOperationException` | 实体没有任何 `[DbKey]` / `[DbColumn]`；`Upsert`/`Update`/`Delete` 没有主键 |
| `ArgumentException` | `GetByKeyAsync` / `DeleteByKeyAsync` 的键数量与主键数不匹配 |
| `SqliteException` | 主键冲突、列不存在、类型不匹配、`SQLITE_BUSY` 超时 |
| `NotSupportedException` | 建表时遇到不支持的类型 |
