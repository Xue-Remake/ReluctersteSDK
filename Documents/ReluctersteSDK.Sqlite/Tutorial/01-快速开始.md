# 01 · 快速开始

**目标**：用一个完整的控制台程序建库、建表、插入、查询、更新、删除，并正确释放。

---

## 1. 创建工程

```powershell
dotnet new console -n SqliteDemo
cd SqliteDemo
dotnet add package ReluctersteSDK.Sqlite --version 0.13.0.0
```

`SqliteDemo.csproj` 至少包含：

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="ReluctersteSDK.Sqlite" Version="0.13.0.0" />
  </ItemGroup>
</Project>
```

## 2. 定义实体

```csharp
using ReluctersteSDK.Sqlite;

[DbTable("players")]
public sealed class PlayerRow
{
    [DbKey("id")]           public long Id { get; set; }
    [DbColumn("name")]      public string Name { get; set; } = "";
    [DbColumn("score")]     public int Score { get; set; }
    [DbColumn("created_at")] public DateTime CreatedAt { get; set; }

    // 没有 [DbKey] / [DbColumn]：不入库
    public string RuntimeOnly { get; set; } = "";
}
```

规则很简单：**只有标了 `[DbKey]` 或 `[DbColumn]` 的属性才会入库**。不需要 `[DbIgnore]`。

## 3. 完整程序

`Program.cs`：

```csharp
using ReluctersteSDK.Sqlite;

string folder = Path.Combine(AppContext.BaseDirectory, "Data");

await using SqliteDataBase db = new SqliteDataBase(folder, "demo.db");
await db.EnsureInitializedAsync();

Console.WriteLine($"数据库：{db.DatabasePath}");

// 1. 建表（CREATE TABLE IF NOT EXISTS）
await db.EnsureTableAsync<PlayerRow>();

// 2. 插入
await db.InsertAsync(new PlayerRow
{
    Id = 1,
    Name = "Alice",
    Score = 10,
    CreatedAt = DateTime.UtcNow
});

await db.InsertAsync(new PlayerRow
{
    Id = 2,
    Name = "Bob",
    Score = 30,
    CreatedAt = DateTime.UtcNow
});

// 3. 按主键读取（找不到返回 null）
PlayerRow? alice = await db.GetByKeyAsync<PlayerRow>(1);
Console.WriteLine($"读回：{alice?.Name} / {alice?.Score}");

// 4. 条件查询
List<PlayerRow> top = await db.QueryAsync<PlayerRow>(
    where: "score >= @min",
    parameters: new { min = 10 },
    orderBy: "score DESC",
    limit: 10);

foreach (PlayerRow row in top)
    Console.WriteLine($"{row.Id}\t{row.Name}\t{row.Score}");

// 5. 更新（按主键，更新全部非键列）
await db.UpdateAsync(new PlayerRow
{
    Id = 1,
    Name = "Alice",
    Score = 99,
    CreatedAt = DateTime.UtcNow
});

alice = await db.GetByKeyAsync<PlayerRow>(1);
Console.WriteLine($"更新后：{alice?.Score}");   // 99

// 6. 插入或更新
await db.UpsertAsync(new PlayerRow
{
    Id = 2,
    Name = "Bob",
    Score = 55,
    CreatedAt = DateTime.UtcNow
});

// 7. 删除
await db.DeleteByKeyAsync<PlayerRow>(2);
Console.WriteLine($"剩余：{(await db.GetAllAsync<PlayerRow>()).Count}");
```

## 4. 每一步发生了什么

| 调用 | 行为 |
|---|---|
| `new SqliteDataBase(folder, "demo.db")` | 创建目录；连接串固定 `Cache=Shared`、`ReadWriteCreate` |
| `EnsureInitializedAsync()` | 幂等初始化：`busy_timeout=5000`、`foreign_keys=ON`、WAL、`synchronous=NORMAL` |
| `EnsureTableAsync<PlayerRow>()` | 反射特性生成 `CREATE TABLE IF NOT EXISTS`，只执行一次建表语句 |
| `InsertAsync` | 参数化 `INSERT`，走全局写锁 |
| `GetByKeyAsync` | 按 `[DbKey]` 生成 `WHERE`，`LIMIT 1`，找不到返回 `null` |
| `QueryAsync` | `where` 片段 + 参数绑定 + `orderBy` + `limit` |
| `UpdateAsync` | 按主键更新**全部非键列** |
| `UpsertAsync` | `INSERT … ON CONFLICT(主键) DO UPDATE` |
| `DisposeAsync` | 等写锁并释放信号量，不关闭长连接（本来就没有） |

生成的表结构（`EnsureTableAsync`）：

```sql
CREATE TABLE IF NOT EXISTS "players" (
    "id" INTEGER NOT NULL,
    "name" TEXT,
    "score" INTEGER NOT NULL,
    "created_at" TEXT,
    PRIMARY KEY ("id")
);
```

`NOT NULL` 的规则是：**键列，或不可空的属性**。`string` 是引用类型，按映射视为可空；`int` 不是 `Nullable<int>`，所以 `score` 带 `NOT NULL`。

## 5. 路径与生命周期

### 用 `FdPath`

```csharp
using ReluctersteSDK.Paths;
using ReluctersteSDK.Sqlite;

var db = new SqliteDataBase(new RelativePath(@"Data\Databases"), "game.db");
```

构造内部会 `PathAnalyzer.Analysis` 绝对化。

### 只 `await using` 一次

```csharp
await using var db = new SqliteDataBase(folder, "demo.db");
await db.EnsureInitializedAsync();

await using var ctx = new RowDbContext(db);
// ❌ 不要同时对 db 和 ctx 使用 await using：
// RowDbContext.DisposeAsync 会调用 db.DisposeAsync
```

`SqliteDataBase.DisposeAsync` 不会让后续调用立刻报错（写路径会 `ObjectDisposedException`，读路径可能仍然成功），不要依赖这个行为。
