# 07 · 数据库迁移

**目标**：给已上线的库加字段、建索引、改表，并保证重复启动安全、失败可回滚、执行有记录。

---

## 1. 最小迁移

```csharp
using ReluctersteSDK.Sqlite;
using ReluctersteSDK.Sqlite.Migrations;

await using var db = new SqliteDataBase(folder, "app.db");
await db.EnsureInitializedAsync();

SqliteMigration[] migrations =
{
    SqliteMigration.Create(1, "创建 players 表", async (context, ct) =>
    {
        await context.CreateTableIfNotExistsAsync<PlayerRow>(ct);
    }),

    SqliteMigration.Create(2, "增加 score 列", async (context, ct) =>
    {
        await context.AddColumnAsync(
            "players", "score", "INTEGER",
            defaultValueSql: "0",
            cancellationToken: ct);
    })
};

MigrationResult result = await db.Migrations.MigrateAsync(migrations);

Console.WriteLine($"本次执行 {result.AppliedCount} 个，跳过 {result.SkippedCount} 个，当前版本 {result.CurrentVersion}");
```

第一次运行：`AppliedCount = 2`，`CurrentVersion = 2`。
第二次运行：`AppliedCount = 0`，`SkippedCount = 2`。

---

## 2. 执行模型

```
MigrateAsync(migrations)
├─ 校验：版本唯一、> 0、说明非空
├─ 按 Version 升序排序
├─ 读取历史表 __schema_migrations
├─ 跳过已应用版本
├─ 对每个待执行迁移：
│   ├─ BEGIN
│   ├─ 调用 UpAsync(context)
│   ├─ 写入历史（version / description / applied_at / execution_ms）
│   └─ COMMIT（失败则 ROLLBACK，不写历史）
└─ 返回 MigrationResult
```

关键规则：

- **每个迁移独立事务**，失败整体回滚；
- **执行期间持有数据库写锁**，普通写操作排队；
- **不支持乱序**：已执行 1、3 之后再补版本 2 会抛 `InvalidOperationException`；
- 版本重复、版本 ≤ 0、说明为空会在开始执行前抛异常；
- 已执行迁移的代码被修改**不会被检测**（没有校验和）；不要改已发布迁移的语义。

## 3. 迁移的两种写法

### 委托形式

```csharp
SqliteMigration.Create(
    version: 3,
    description: "给 players 建索引",
    up: async (context, ct) =>
    {
        await context.CreateIndexAsync(
            "ix_players_name", "players", new[] { "name" },
            cancellationToken: ct);
    },
    down: async (context, ct) =>
    {
        await context.DropIndexAsync("ix_players_name", ct);
    });
```

`down` 可省略；省略后该迁移**不可回滚**。

### 子类形式

```csharp
public sealed class AddPlayerLevelMigration : SqliteMigration
{
    public override long Version => 4;
    public override string Description => "给 players 增加 level 列";

    public override async Task UpAsync(
        SqliteMigrationContext context,
        CancellationToken cancellationToken = default)
    {
        if (!await context.ColumnExistsAsync("players", "level", cancellationToken))
        {
            await context.AddColumnAsync(
                "players", "level", "INTEGER",
                defaultValueSql: "1",
                cancellationToken: cancellationToken);
        }
    }

    public override async Task DownAsync(
        SqliteMigrationContext context,
        CancellationToken cancellationToken = default)
    {
        await context.DropColumnAsync("players", "level", cancellationToken);
    }
}
```

子类适合需要多个步骤、共享常量或复用逻辑的迁移。

## 4. 上下文能力

### 执行与查询

| 方法 | 说明 |
|---|---|
| `ExecuteAsync(sql, parameters = null, ct)` | 执行 DDL/DML，返回受影响行数 |
| `ExecuteScalarAsync(sql, parameters = null, ct)` | 首行首列 |
| `QueryAsync<T>(sql, projector, parameters = null, ct)` | 自定义行投影 |

所有命令都挂在当前迁移的事务上。

### 结构探测

```csharp
bool exists = await context.TableExistsAsync("players", ct);
bool hasColumn = await context.ColumnExistsAsync("players", "score", ct);
IReadOnlyList<SqliteColumnInfo> columns = await context.GetColumnsAsync("players", ct);

foreach (SqliteColumnInfo col in columns)
    Console.WriteLine($"{col.Name} {col.DeclaredType} pk={col.PrimaryKeyOrder}");
```

`SqliteColumnInfo`：`Name`、`DeclaredType`、`IsNotNull`、`DefaultValue`、`PrimaryKeyOrder`（0 表示非主键）。

### DDL 助手

| 方法 | 生成 |
|---|---|
| `CreateTableIfNotExistsAsync<T>()` | 按特性映射建表 |
| `AddColumnAsync(table, column, type, notNull, defaultValueSql)` | `ALTER TABLE … ADD COLUMN` |
| `RenameColumnAsync(table, old, new)` | `ALTER TABLE … RENAME COLUMN`（SQLite 3.25+） |
| `DropColumnAsync(table, column)` | `ALTER TABLE … DROP COLUMN`（SQLite 3.35+） |
| `RenameTableAsync(old, new)` | `ALTER TABLE … RENAME TO` |
| `DropTableAsync(table)` | `DROP TABLE IF EXISTS` |
| `CreateIndexAsync(index, table, columns, unique, whereSql)` | `CREATE [UNIQUE] INDEX IF NOT EXISTS` |
| `DropIndexAsync(index)` | `DROP INDEX IF EXISTS` |

表名、列名自动加引号；`type`、`defaultValueSql`、`whereSql` 是**原始 SQL 片段**，只传代码常量。

## 5. 安全地加列

给已有数据的表加 `NOT NULL` 列必须提供默认值：

```csharp
// ✅ 有默认值
await context.AddColumnAsync(
    "players", "level", "INTEGER",
    notNull: true,
    defaultValueSql: "1",
    cancellationToken: ct);

// ❌ 空表默认值会让 SQLite 报错
await context.AddColumnAsync("players", "level", "INTEGER", notNull: true, cancellationToken: ct);
```

更稳妥的写法是先探测：

```csharp
if (!await context.ColumnExistsAsync("players", "level", ct))
{
    await context.AddColumnAsync(
        "players", "level", "INTEGER",
        defaultValueSql: "1",
        cancellationToken: ct);
}
```

这样即使某个环境已经手工加过列，迁移也不会失败。

## 6. 回滚

```csharp
// 回滚版本 > 1 的全部迁移（按版本降序）
MigrationResult result = await db.Migrations.RollbackAsync(migrations, targetVersion: 1);

// 全部回滚
await db.Migrations.RollbackAsync(migrations);
```

规则：

- 待回滚的迁移必须出现在传入的 `migrations` 集合中；
- 没写 `DownAsync` 的迁移回滚时抛 `NotSupportedException`，该迁移事务回滚、历史记录保留；
- 回滚按版本**降序**执行；
- 回滚同样逐迁移独立事务。

```csharp
public override async Task DownAsync(
    SqliteMigrationContext context,
    CancellationToken cancellationToken = default)
{
    await context.DropColumnAsync("players", "score", cancellationToken);
}
```

## 7. 结果与历史

```csharp
public sealed class MigrationResult
{
    public IReadOnlyList<AppliedMigration> Applied { get; }
    public IReadOnlyList<AppliedMigration> Reverted { get; }
    public int AppliedCount { get; }
    public int RevertedCount { get; }
    public int SkippedCount { get; }
    public long PreviousVersion { get; }
    public long CurrentVersion { get; }
    public bool HasChanges { get; }
}
```

```csharp
IReadOnlyList<AppliedMigration> history =
    await db.Migrations.GetAppliedMigrationsAsync();

foreach (AppliedMigration m in history)
    Console.WriteLine($"{m.Version}\t{m.AppliedAt:O}\t{m.ExecutionMilliseconds} ms\t{m.Description}");
```

默认历史表：

```sql
CREATE TABLE IF NOT EXISTS "__schema_migrations" (
    "version"      INTEGER NOT NULL PRIMARY KEY,
    "description"  TEXT    NOT NULL,
    "applied_at"   TEXT    NOT NULL,
    "execution_ms" INTEGER NOT NULL
);
```

可以自定义表名：

```csharp
var runner = new SqliteMigrationRunner(db, "__my_migrations");
```

## 8. 异常处理

```csharp
try
{
    MigrationResult result = await db.Migrations.MigrateAsync(migrations);
}
catch (SqliteMigrationException ex)
{
    Console.WriteLine($"迁移 {ex.Version} 在 {ex.Direction} 阶段失败：{ex.InnerException?.Message}");
}
catch (InvalidOperationException ex)
{
    Console.WriteLine($"迁移顺序有问题：{ex.Message}");
}
catch (OperationCanceledException)
{
    Console.WriteLine("迁移已取消；当前迁移已回滚");
}
```

| 异常 | 场景 |
|---|---|
| `ArgumentException` | 版本重复、说明为空、集合含 null |
| `ArgumentOutOfRangeException` | 版本 ≤ 0，或回滚目标为负 |
| `InvalidOperationException` | 乱序迁移、回滚缺定义 |
| `SqliteMigrationException` | 迁移执行失败，带 `Version` / `Description` / `Direction` |
| `OperationCanceledException` | 取消令牌触发，当前事务回滚 |

## 9. 完整示例：启动时自动升级

```csharp
using ReluctersteSDK.Sqlite;
using ReluctersteSDK.Sqlite.Migrations;

public static class DatabaseBootstrap
{
    public static async Task<SqliteDataBase> OpenAsync(string folder)
    {
        var db = new SqliteDataBase(folder, "app.db");
        await db.EnsureInitializedAsync();

        MigrationResult result = await db.Migrations.MigrateAsync(BuildMigrations());

        Console.WriteLine(result.HasChanges
            ? $"数据库升级到 v{result.CurrentVersion}（本次 {result.AppliedCount} 个）"
            : $"数据库已是最新 v{result.CurrentVersion}");

        return db;
    }

    private static SqliteMigration[] BuildMigrations() => new SqliteMigration[]
    {
        SqliteMigration.Create(1, "初始化 players", async (ctx, ct) =>
            await ctx.CreateTableIfNotExistsAsync<PlayerRow>(ct)),

        SqliteMigration.Create(
            2, "增加 score",
            up: async (ctx, ct) =>
            {
                if (!await ctx.ColumnExistsAsync("players", "score", ct))
                    await ctx.AddColumnAsync("players", "score", "INTEGER", defaultValueSql: "0", cancellationToken: ct);
            },
            down: async (ctx, ct) =>
            {
                if (await ctx.ColumnExistsAsync("players", "score", ct))
                    await ctx.DropColumnAsync("players", "score", ct);
            }),

        SqliteMigration.Create(
            3, "给 score 建索引",
            up: async (ctx, ct) =>
                await ctx.CreateIndexAsync("ix_players_score", "players", new[] { "score" }, cancellationToken: ct),
            down: async (ctx, ct) =>
                await ctx.DropIndexAsync("ix_players_score", ct))
    };
}
```

## 10. 限制

- 不做实体差异推断：加字段必须写迁移；
- 不支持乱序补丁；
- 没有校验和：已执行迁移被改不会被发现；
- 迁移内不能切换 `PRAGMA foreign_keys`（事务中无效）；
- 整体持有写锁：大表重建会阻塞其它写；
- 回滚依赖 `DownAsync`，默认不可回滚；
- 历史表与业务表同库，迁移不要删除/改写它。
