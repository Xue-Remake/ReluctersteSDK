# 01 · 快速开始

**目标**：搭一个能跑的 MonoGame 工程，屏幕上出现一个向右移动的方块。你会用到 `World`、`Transform`、`Velocity`、`Sprite`、`MotionSystem`、`TransformSystem`、`SpriteRenderSystem`。

---

## 1. 创建工程

```powershell
dotnet new console -n MyGame
cd MyGame
```

`MyGame.csproj`：

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
```

## 3. 最小世界

`MinimalGame.cs`：

```csharp
using Microsoft.Xna.Framework;
using Microsoft.Xna.Framework.Graphics;
using Microsoft.Xna.Framework.Input;
using ReluctersteSDK.Game.Ecs;
using ReluctersteSDK.Game.Rendering;
using ReluctersteSDK.Game.Systems;
using ReluctersteSDK.Math.Vectors;

namespace MyGame;

public sealed class MinimalGame : Game
{
    private readonly GraphicsDeviceManager _graphics;

    private SpriteBatch _spriteBatch = null!;
    private Texture2D _pixel = null!;
    private World _world = null!;
    private SpriteRenderSystem _renderSystem = null!;

    public MinimalGame()
    {
        _graphics = new GraphicsDeviceManager(this)
        {
            PreferredBackBufferWidth = 1280,
            PreferredBackBufferHeight = 720
        };

        Content.RootDirectory = "Content";
        IsMouseVisible = true;
        Window.Title = "ReluctersteSDK.Game · 01 快速开始";
    }

    protected override void LoadContent()
    {
        _spriteBatch = new SpriteBatch(GraphicsDevice);

        // 不依赖内容管线：1×1 白纹理，靠 Transform.LocalScale 放大成方块
        _pixel = new Texture2D(GraphicsDevice, 1, 1);
        _pixel.SetData(new[] { Color.White });

        _world = new World();
        _renderSystem = new SpriteRenderSystem();

        // 同一阶段内 priority 升序执行：
        // MotionSystem 先推进位置，TransformSystem 再算世界矩阵
        _world.AddSystem(new MotionSystem(), SystemPhase.Update, priority: -10);
        _world.AddSystem(new TransformSystem(), SystemPhase.Update, priority: 10);
        _world.AddSystem(_renderSystem, SystemPhase.Render);

        Entity box = _world.Create();

        _world.Add(box, new Transform
        {
            LocalPosition = new CartesianVector2D(160, 360),
            LocalRotation = 0f,
            LocalScale = new CartesianVector2D(32, 32)
        });

        _world.Add(box, new Velocity
        {
            Value = new CartesianVector2D(120, 0)   // 120 单位/秒
        });

        _world.Add(box, new Sprite(_pixel)
        {
            Origin = new Vector2(0.5f, 0.5f)        // 以方块中心为锚点
        });
    }

    protected override void Update(GameTime gameTime)
    {
        if (Keyboard.GetState().IsKeyDown(Keys.Escape))
            Exit();

        float dt = (float)gameTime.ElapsedGameTime.TotalSeconds;
        _world.Update(dt);

        base.Update(gameTime);
    }

    protected override void Draw(GameTime gameTime)
    {
        GraphicsDevice.Clear(new Color(24, 26, 32));

        float dt = (float)gameTime.ElapsedGameTime.TotalSeconds;

        // 1) Render 阶段：SpriteRenderSystem.Execute 收集 (Transform, Sprite) 实体
        _world.Render(dt);

        // 2) 托管侧排序后提交；Begin 必须是 Deferred
        _spriteBatch.Begin(
            sortMode: SpriteSortMode.Deferred,
            samplerState: SamplerState.PointClamp);

        _renderSystem.Submit(_spriteBatch);

        _spriteBatch.End();

        base.Draw(gameTime);
    }

    protected override void UnloadContent()
    {
        _world.Dispose();
        _pixel.Dispose();
        _spriteBatch.Dispose();

        base.UnloadContent();
    }
}
```

运行：

```powershell
dotnet run
```

## 4. 这几行到底发生了什么

| 代码 | 作用 |
|---|---|
| `new World()` | 创建实体分配器、组件存储表、命令缓冲与事件容器 |
| `world.Create()` | 分配一个实体句柄（`Index` + `Generation`） |
| `world.Add(e, Transform.Identity)` | 把 `Transform` 结构体放进该类型的 Sparse Set |
| `world.AddSystem(..., priority: -10)` | 注册到 Update 阶段，优先级小的先跑 |
| `world.Update(dt)` | 首次调用会自动 `Start()`；然后交换事件缓冲、跑 Update → LateUpdate、回放命令 |
| `world.Render(dt)` | 跑 Render 阶段（这里就是 `SpriteRenderSystem.Execute`） |
| `renderSystem.Submit(batch)` | 按 Layer → Depth → 纹理 → 实体索引排序后逐条 `Draw` |

`MotionSystem` 每帧做的是：

```
v += a·dt            （没有 Acceleration 时 a = 0）
position += v·dt     （用更新后的 v）
```

`TransformSystem` 把局部变换累乘成 `WorldTransform`；没有父节点时世界矩阵就等于局部矩阵。

## 5. 常见启动问题

| 现象 | 原因 |
|---|---|
| 窗口一片黑，没有方块 | `Transform.LocalScale` 没设，`default` 是 `(0,0)`；或用 `default(Transform)` 代替了 `Transform.Identity` |
| 方块在左上角且很小 | `Origin` 默认 `(0,0)`，且纹理只有 1×1；示例用 `LocalScale` 放大、`Origin` 居中 |
| 画面顺序不对 | `SpriteBatch.Begin` 用了 `SpriteSortMode.Texture` 等；必须 `Deferred` |
| `dotnet run` 找不到原生库 | MonoGame DesktopGL 需要对应平台的 native 包；确认引用了 `MonoGame.Framework.DesktopGL` 而不是 `MonoGame.Framework.WindowsDX` 混用 |
| 窗口一闪而过 | 控制台工程的 `Main` 结束；用 `using var game = new …; game.Run();` 阻塞到窗口关闭 |
