# 11 · 快照与存档

**目标**：把世界里的实体、组件、单例与父子关系保存成 JSON，再完整恢复；知道哪些东西**不会**被保存。

---

## 1. 先注册组件

快照是**白名单**：只有注册过的组件类型才会参与序列化。

```csharp
using ReluctersteSDK.Game.Ecs;
using ReluctersteSDK.Game.Ecs.Serialization;

public struct Health
{
    public int Value;
    public int Max;
}

public struct Inventory
{
    public int Gold;
    public int Potions;
}

var registry = ComponentCodecRegistry.CreateDefault();
registry.Register<Health>();
registry.Register<Inventory>();
```

`CreateDefault()` 已包含：`Transform`、`Parent`、`Velocity`、`Acceleration`、`Damping`、`Heading`。

自定义类型也可以指定稳定的名字：

```csharp
registry.Register<Inventory>("inventory");
```

名字会写进 JSON；**改动名字会让旧存档读不出来**。

## 2. 捕获与恢复

```csharp
WorldSnapshot snapshot = WorldSnapshotSerializer.Capture(world, registry);

// 恢复到另一个世界
var target = new World();
WorldSnapshotSerializer.Restore(target, snapshot, registry);
```

`Restore` 的语义：

- 保存每个存活实体的 `Index` + `Generation`，恢复后句柄保持一致；
- `Parent` 会保存，`Children` 由 `Parent` 重建；
- **`WorldTransform` 不保存**，恢复后由 `TransformSystem` 重算；
- 恢复期间走正常路径，触发 `EntityCreated` / `ComponentAdded`；
- 目标世界非空时，默认先 `ClearForRestore()`（保留系统）。

## 3. 直接读写文件

```csharp
using System.IO;

// 保存
using (FileStream stream = File.Create("save.json"))
{
    WorldSnapshotSerializer.Save(world, stream, registry);
}

// 读取
using (FileStream stream = File.OpenRead("save.json"))
{
    WorldSnapshotSerializer.Load(targetWorld, stream, registry);
}
```

`Save` 内部先 `Capture` 再 `JsonSerializer.Serialize`；`Load` 反序列化后调用 `Restore`。

建议写入临时文件再原子替换，避免进程中断留下半个存档：

```csharp
string temp = path + ".tmp";
using (FileStream stream = File.Create(temp))
    WorldSnapshotSerializer.Save(world, stream, registry);

File.Move(temp, path, overwrite: true);
```

## 4. 选项

```csharp
var options = new WorldSnapshotOptions
{
    ClearBeforeRestore = true,
    IncludeSingletons = true,
    ThrowOnUnsupportedComponent = true
};

WorldSnapshotSerializer.Save(world, stream, registry, options);
```

| 选项 | 默认 | 说明 |
|---|---|---|
| `ClearBeforeRestore` | `true` | 目标世界非空时先清空实体/组件（保留系统） |
| `IncludeSingletons` | `true` | 是否保存单例组件 |
| `ThrowOnUnsupportedComponent` | `true` | 遇到未注册类型时抛异常；`false` 则跳过 |
| `JsonOptions` | `SnapshotJson.CreateOptions()` | JSON 选项与转换器 |

`SnapshotJson.CreateOptions()` 已开启 `IncludeFields = true`，因此 public 字段的组件能正确序列化。

## 5. 单例与层级

```csharp
public struct GameState
{
    public int Wave;
    public float PlayTime;
}

world.SetSingleton(new GameState { Wave = 3, PlayTime = 42.5f });

// 捕获时会一并保存（IncludeSingletons = true）
WorldSnapshot snapshot = WorldSnapshotSerializer.Capture(world, registry);

// 恢复后单例还在
ref GameState state = ref target.GetSingleton<GameState>();
Console.WriteLine(state.Wave);   // 3
```

单例类型也要注册：

```csharp
registry.Register<GameState>();
```

层级：

```csharp
Entity body = world.Create();
Entity sword = world.Create();
world.Add(body, Transform.Identity);
world.Add(sword, Transform.Identity);
world.SetParent(sword, body);

// 恢复后 GetParent(sword) == body（按 Index/Generation 对应）
```

## 6. 不参与快照的东西

| 类型 | 原因 |
|---|---|
| `Sprite` / `Animator` | 持有 `Texture2D` 等运行时资源 |
| `Texture2D` / `SpriteBatch` | 设备资源 |
| 系统实例 | 系统应重新 `AddSystem` |
| `World.Events` | 事件是“刚发生过什么”，不是状态 |
| `Commands` | 待执行命令不回放 |
| `WorldTransform` | 派生数据，由 `TransformSystem` 重算 |
| 未注册的组件 | 白名单之外一律不保存 |

存档时需要保留的玩法数据，请做成**纯数据组件**并注册。

## 7. 完整示例：存读档

```csharp
using System.IO;
using ReluctersteSDK.Game.Ecs;
using ReluctersteSDK.Game.Ecs.Serialization;

public static class SaveGame
{
    public static ComponentCodecRegistry CreateRegistry()
    {
        var registry = ComponentCodecRegistry.CreateDefault();
        registry.Register<Health>();
        registry.Register<Inventory>();
        registry.Register<GameState>();
        return registry;
    }

    public static void Save(World world, string path)
    {
        ComponentCodecRegistry registry = CreateRegistry();

        string temp = path + ".tmp";
        using (FileStream stream = File.Create(temp))
            WorldSnapshotSerializer.Save(world, stream, registry);

        File.Move(temp, path, overwrite: true);
    }

    public static void Load(World world, string path)
    {
        ComponentCodecRegistry registry = CreateRegistry();

        using FileStream stream = File.OpenRead(path);
        WorldSnapshotSerializer.Load(world, stream, registry);
    }
}
```

使用：

```csharp
SaveGame.Save(world, "slot1.json");

// 新世界：系统要重新注册
var loaded = new World();
loaded.AddSystem(new MotionSystem(), SystemPhase.Update, -10);
loaded.AddSystem(new TransformSystem(), SystemPhase.Update, 10);
SaveGame.Load(loaded, "slot1.json");

loaded.Update(0.016f);   // 让 TransformSystem 重算 WorldTransform
```

## 8. 常见问题

| 现象 | 原因 |
|---|---|
| 恢复后某个组件没了 | 类型没注册，或 `ThrowOnUnsupportedComponent = false` 被静默跳过 |
| 恢复后子物体位置不对 | 只恢复了 `Parent`；`WorldTransform` 要等 `TransformSystem` 跑一帧 |
| 单例丢了 | 没注册单例类型，或 `IncludeSingletons = false` |
| `目标世界非空` 异常 | 关闭了 `ClearBeforeRestore`；先手动 `world.Clear()` |
| 旧存档读不出来 | 注册名被改过；保持 `Register<T>` 的名字稳定 |
| 自定义组件字段没保存 | 字段是 `private`，或类型包含无法序列化的成员 |
