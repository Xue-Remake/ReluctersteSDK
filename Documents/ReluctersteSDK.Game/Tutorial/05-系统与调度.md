# 05 · 系统与调度

**目标**：写一个自定义系统，控制它的阶段、优先级与启停，并理解 `Start` / `Update` / `Render` / `Shutdown` 的执行顺序。

---

## 1. 最小系统

```csharp
using ReluctersteSDK.Game.Ecs;

public sealed class HealthRegenSystem : ISystem
{
    public void Execute(World world, float deltaTime)
    {
        world.Query<Health>().ForEach((Entity e, ref Health h) =>
        {
            if (h.Value < h.Max)
                h.Value = Math.Min(h.Max, h.Value + (int)(5 * deltaTime));
        });
    }
}
```

`ISystem` 只有三个成员：

```csharp
public interface ISystem
{
    void Execute(World world, float deltaTime);
    void OnStart(World world) { }   // 默认空实现
    void OnStop(World world) { }
}
```

---

## 2. 注册到阶段

```csharp
world.AddSystem(new HealthRegenSystem(), SystemPhase.Update, priority: 0);
```

| 阶段 | 何时执行 | 典型用途 |
|---|---|---|
| `Startup` | `World.Start()` | 关卡初始化、资源预加载 |
| `Update` | `World.Update(dt)` | 输入、AI、运动、变换 |
| `LateUpdate` | `World.Update(dt)` 之后 | 相机跟随、收尾、排序 |
| `Render` | `World.Render(dt)` | 收集渲染命令 |
| `Teardown` | `World.Shutdown()` | 释放资源、写存档 |

同一阶段内：**priority 升序；相同 priority 按注册顺序**。

```csharp
world.AddSystem(new InputSystem(),       SystemPhase.Update, priority: -100);
world.AddSystem(new MotionSystem(),      SystemPhase.Update, priority: -10);
world.AddSystem(new AiSystem(),          SystemPhase.Update, priority: 0);
world.AddSystem(new TransformSystem(),   SystemPhase.Update, priority: 10);
world.AddSystem(new CameraFollowSystem(),SystemPhase.LateUpdate);
world.AddSystem(new SpriteRenderSystem(),SystemPhase.Render);
```

## 3. 启动、更新、关闭

```csharp
var world = new World();
world.AddSystem(new BootstrapSystem(), SystemPhase.Startup);
world.AddSystem(new GameLoopSystem(), SystemPhase.Update);
world.AddSystem(new CleanupSystem(), SystemPhase.Teardown);

world.Start();       // 所有系统 OnStart → Startup 阶段 → 回放命令
world.Update(0.016f);// Events.Swap → Update → LateUpdate → 回放命令
world.Render(0.016f);// Render → 回放命令
world.Shutdown();    // Teardown → 回放命令 → 所有系统 OnStop
```

`World.Update` 在第一次调用时会自动 `Start()`，所以简单场景可以不显式调用。但如果你希望 `Startup` 在任何一帧之前完成，就显式写 `world.Start()`。

### 每个系统后自动回放命令

```
for each system in phase:
    system.Execute(world, dt)
    world.Commands.Playback(world)
```

因此**下一个系统能看到上一个系统通过 `Commands` 做的结构修改**。这是 ECS 里“生成子弹”“销毁敌人”能按顺序生效的基础。

## 4. 启停与移除

```csharp
ISystem ai = new AiSystem();
world.AddSystem(ai, SystemPhase.Update);

world.SetSystemEnabled(ai, false);   // 保留注册，不执行
Console.WriteLine(world.IsSystemEnabled(ai));   // False

world.SetSystemEnabled(ai, true);
world.SetSystemPriority(ai, -50);    // 重新排序

world.RemoveSystem(ai);              // 移除并调用 OnStop（如果世界已启动）
```

注意：

- `RemoveSystem` 用**引用相等**查找；每次 `new` 一个实例注册，旧实例就删不掉；
- 运行中的系统增删系统：`ExecutePhase` 使用快照数组，**从下一帧生效**；
- `SetSystemEnabled` / `SetSystemPriority` 修改后会重建 `UpdateSystems` / `RenderSystems` 视图。

### 查看注册表

```csharp
foreach (SystemEntry entry in world.GetSystems(SystemPhase.Update))
{
    Console.WriteLine($"{entry.System.GetType().Name} " +
                      $"phase={entry.Phase} priority={entry.Priority} " +
                      $"enabled={entry.Enabled} order={entry.RegistrationOrder}");
}
```

## 5. 生命周期钩子

```csharp
public sealed class SpawnSystem : ISystem
{
    private Entity _player;

    public void OnStart(World world)
    {
        _player = world.Create();
        world.Add(_player, Transform.Identity);
        Console.WriteLine("SpawnSystem started");
    }

    public void Execute(World world, float deltaTime) { }

    public void OnStop(World world)
    {
        Console.WriteLine("SpawnSystem stopped");
    }
}
```

时机：

- `OnStart`：世界启动时对**已启用**的系统调用一次；世界已启动后再 `AddSystem` 会立刻调用；
- `OnStop`：`RemoveSystem` 或 `Shutdown` 时调用；
- `Startup` 阶段的 `Execute` 在全部 `OnStart` 之后执行；
- `Teardown` 阶段的 `Execute` 在全部 `OnStop` 之前执行。

## 6. 完整示例：带启动与收尾的系统

```csharp
using ReluctersteSDK.Game.Ecs;

public sealed class RoundSystem : ISystem
{
    private int _round;

    public void OnStart(World world)
    {
        _round = 1;
        Console.WriteLine($"Round {_round} start");
    }

    public void Execute(World world, float deltaTime)
    {
        // 每 10 秒进入下一回合
        _timer += deltaTime;
        if (_timer >= 10f)
        {
            _timer = 0f;
            _round++;
            Console.WriteLine($"Round {_round}");
        }
    }

    public void OnStop(World world)
    {
        Console.WriteLine($"Round {_round} end");
    }

    private float _timer;
}

var world = new World();
var rounds = new RoundSystem();

world.AddSystem(new MotionSystem(), SystemPhase.Update, priority: -10);
world.AddSystem(rounds, SystemPhase.Update);
world.AddSystem(new TransformSystem(), SystemPhase.Update, priority: 10);

world.Start();                 // Round 1 start
for (int i = 0; i < 600; i++)  // 10 秒 @ 60 FPS
    world.Update(1f / 60f);    // Round 2

world.Shutdown();              // Round 2 end
```

## 7. 自定义系统的常用形态

### 输入 → 写组件

```csharp
public sealed class InputSystem : ISystem
{
    public void Execute(World world, float deltaTime)
    {
        KeyboardState kb = Keyboard.GetState();
        CartesianVector2D dir = CartesianVector2D.Zero;

        if (kb.IsKeyDown(Keys.A)) dir += new CartesianVector2D(-1, 0);
        if (kb.IsKeyDown(Keys.D)) dir += new CartesianVector2D(1, 0);
        if (kb.IsKeyDown(Keys.W)) dir += new CartesianVector2D(0, -1);
        if (kb.IsKeyDown(Keys.S)) dir += new CartesianVector2D(0, 1);

        world.Query<PlayerTag, Acceleration>().ForEach(
            (Entity e, ref PlayerTag _, ref Acceleration a) =>
                a.Value = dir * 900f);
    }
}
```

### 只读收尾

```csharp
public sealed class CameraFollowSystem : ISystem
{
    private readonly Camera2D _camera;
    public CameraFollowSystem(Camera2D camera) => _camera = camera;

    public void Execute(World world, float deltaTime)
    {
        world.Query<PlayerTag, WorldTransform>().ForEach(
            (Entity e, ref PlayerTag _, ref WorldTransform wt) =>
                _camera.Position = new CartesianVector2D(wt.Value.M31, wt.Value.M32));
    }
}
```

（`Camera2D` 的完整用法见 [07-渲染与摄像机.md](07-渲染与摄像机.md)。）

## 8. 调试系统顺序

```csharp
world.StatisticsEnabled = true;
world.Update(dt);

foreach (SystemTiming t in world.SystemTimings)
    Console.WriteLine($"{t.Phase,-10} {t.Milliseconds,6:F3} ms  {t.SystemName}");
```

如果某帧顺序不对，先打印这张表，再核对优先级与注册顺序。
