# 02 · 实体、组件与单例

**目标**：掌握实体的创建与销毁、组件的增删改查、单例组件，以及生命周期事件。这一章不涉及渲染，全部代码可以在纯控制台测试里跑（`ReluctersteSDK.Game` 的 `Ecs/` 不依赖 MonoGame）。

---

## 1. 定义组件

组件只放数据，不放行为：

```csharp
using ReluctersteSDK.Game.Ecs;
using ReluctersteSDK.Math.Vectors;

public struct Health
{
    public int Value;
    public int Max;
}

public struct Attack
{
    public int Damage;
    public float Range;
}

public struct Team
{
    public int Id;
}
```

约束：

- 组件类型必须是 `notnull`；`Nullable<T>` 不能直接做组件，需要时把字段写成 `int?`；
- 推荐 `struct`：零装箱、连续存储。需要可变引用语义的容器（如 `Children`）才用 `class`。

---

## 2. 创建与销毁

```csharp
var world = new World();

Entity player = world.Create();
world.Add(player, new Health { Value = 100, Max = 100 });
world.Add(player, new Attack { Damage = 10, Range = 2f });

Console.WriteLine(world.IsAlive(player));   // True

world.Destroy(player);

Console.WriteLine(world.IsAlive(player));   // False
Console.WriteLine(world.Has<Health>(player)); // False —— 组件已级联清理
```

### 句柄复用与 Generation

```csharp
Entity a = world.Create();
world.Destroy(a);

Entity b = world.Create();      // 很可能复用 a 的 Index
Console.WriteLine(a.Index == b.Index);        // True
Console.WriteLine(a == b);                    // False —— Generation 不同
Console.WriteLine(world.IsAlive(a));          // False
```

所以**永远保存 `Entity`，不要保存 `int` 索引**。`Entity` 只有 8 字节，可以直接放进 `List<Entity>`、`Dictionary<Entity, …>`。

### 销毁父节点

`Destroy(parent)` 不会级联销毁子节点：子节点会先被摘掉 `Parent`，升级为根。详见 [04-层级与变换.md](04-层级与变换.md)。

## 3. 组件的读写

```csharp
// 添加或覆盖
world.Add(player, new Health { Value = 80, Max = 100 });

// 取值引用：直接改就是改存储
ref Health health = ref world.Get<Health>(player);
health.Value -= 10;

// 安全检查
if (world.TryGet<Health>(player, out Health copy))
    Console.WriteLine(copy.Value);          // 注意：copy 是副本，改了不落回

if (world.Has<Attack>(player))
    Console.WriteLine("有攻击组件");

bool removed = world.Remove<Attack>(player); // 确实移除返回 true
```

| 方法 | 失效实体 | 缺组件 | 返回 |
|---|---|---|---|
| `Get<T>` | 抛 `ArgumentException` | 抛 `KeyNotFoundException` | `ref T` |
| `TryGet<T>` | 返回 `false` | 返回 `false` | 副本 |
| `Has<T>` | 返回 `false` | 返回 `false` | `bool` |
| `Remove<T>` | 返回 `false` | 返回 `false` | `bool` |
| `Add<T>` | 抛 `ArgumentException` | — | 覆盖时不分新旧 |

> `TryGet` 拿到的是**结构体副本**。要修改请用 `Get` 的引用，或 `Add` 覆盖。

### 覆盖不会触发“新增”语义

```csharp
world.Add(e, new Health { Value = 100 });
world.Add(e, new Health { Value = 50 });   // 覆盖
```

第二次 `Add`：

- 不会产生两份组件；
- 不会自增 `StructuralVersion`；
- 不会触发 `ComponentAdded` 事件。

## 4. 直接操作存储

`world.Store<T>()` 返回 `ComponentStore<T>`，适合手写热循环：

```csharp
ComponentStore<Health> store = world.Store<Health>();

ReadOnlySpan<Entity> entities = store.Entities;
Span<Health> components = store.Components;

for (int i = 0; i < entities.Length; i++)
    components[i].Value = Math.Min(components[i].Value + 1, components[i].Max);
```

要点：

- `Entities` 与 `Components` **同序**，`entities[i]` 对应 `components[i]`；
- 删除使用 **swap-remove**：删中间元素会把最后一个搬过来，**顺序不稳定**；
- 通过 `Store<T>()` 的 `Add` / `Remove` 也会维护 `StructuralVersion` 与生命周期事件；
- `Span` / `ReadOnlySpan` 不能存字段、不能跨 `await`。

## 5. 单例组件

“全局只有一份”的数据（时间、输入快照、游戏状态）用单例组件，不必造一个实体：

```csharp
public struct GameClock
{
    public float Elapsed;
    public int Frame;
}

world.SetSingleton(new GameClock { Elapsed = 0f, Frame = 0 });

ref GameClock clock = ref world.GetSingleton<GameClock>();
clock.Elapsed += 0.016f;
clock.Frame++;

if (world.TryGetSingleton<GameClock>(out GameClock snapshot))
    Console.WriteLine(snapshot.Frame);

world.RemoveSingleton<GameClock>();
```

- `GetSingleton<T>()` 不存在时抛 `KeyNotFoundException`；
- `SetSingleton` 覆盖已有值**不会**自增结构版本；
- 单例也参与快照（默认开启），见 [11-快照与存档.md](11-快照与存档.md)。

## 6. 生命周期事件

```csharp
world.EntityCreated   += e => Console.WriteLine($"created {e}");
world.EntityDestroyed += e => Console.WriteLine($"destroyed {e}");
world.ComponentAdded  += a => Console.WriteLine($"added {a.ComponentType.Name} on {a.Entity}");
world.ComponentRemoved+= a => Console.WriteLine($"removed {a.ComponentType.Name} on {a.Entity}");
world.WorldCleared    += () => Console.WriteLine("world cleared");

Entity e = world.Create();
world.Add(e, new Health { Value = 1 });   // ComponentAdded
world.Destroy(e);                          // ComponentRemoved（每个组件一次）+ EntityDestroyed
```

注意：

- `ComponentAdded` **只在新建时触发**，覆盖不触发；
- `Destroy` 会为实体持有的每种组件各触发一次 `ComponentRemoved`；
- 事件处理器里可以安全地访问 `World`，但**不要在 `Query.ForEach` 内部改结构**（见下一章）。

---

## 7. 清空与释放

```csharp
world.Clear();      // 清空实体、组件、单例、系统、命令、事件；世界还能继续用
world.Dispose();    // 释放；之后除 IsDisposed / Dispose 外的公开操作抛 ObjectDisposedException
```

`Clear` 会触发 `WorldCleared`；`Dispose` 会先 `Shutdown()`（跑 Teardown 与 `OnStop`）再清空。

---

## 8. 完整可运行片段

```csharp
using ReluctersteSDK.Game.Ecs;

var world = new World();
world.ComponentAdded += a => Console.WriteLine($"+{a.ComponentType.Name}");
world.ComponentRemoved += a => Console.WriteLine($"-{a.ComponentType.Name}");

Entity e = world.Create();
world.Add(e, new Health { Value = 30, Max = 30 });
world.Add(e, new Attack { Damage = 5, Range = 1.5f });

ref Health h = ref world.Get<Health>(e);
h.Value = 10;

Console.WriteLine(world.Has<Attack>(e));   // True
world.Remove<Attack>(e);                    // -Attack
world.Destroy(e);                           // -Health + EntityDestroyed
Console.WriteLine(world.IsAlive(e));        // False
```
