# 08 · 帧动画

**目标**：把一张序列图切成 idle / run / attack 三段动画，按输入切换，并在攻击播完后自动回到 idle。

---

## 1. 切序列图

```csharp
using Microsoft.Xna.Framework;
using ReluctersteSDK.Game.Rendering;

// 纹理：48×32，每帧 16×16，columns=3（每行 3 帧，共 2 行）
Rectangle[] allFrames = SpriteSheet.Slice(
    texture,
    frameWidth: 16,
    frameHeight: 16,
    columns: 3);

// idle：第 0~1 帧
Rectangle[] idleFrames = SpriteSheet.Slice(
    texture, 16, 16, columns: 3, startIndex: 0, frameCount: 2);

// run：第 3~5 帧
Rectangle[] runFrames = SpriteSheet.Slice(
    texture, 16, 16, columns: 3, startIndex: 3, frameCount: 3);

// attack：第 6~8 帧
Rectangle[] attackFrames = SpriteSheet.Slice(
    texture, 16, 16, columns: 3, startIndex: 6, frameCount: 3);
```

编号是**行优先**：

```
0 1 2
3 4 5
6 7 8
```

参数规则：

| 参数 | 说明 |
|---|---|
| `columns` | 每行帧数；`<= 0` 时按 `textureWidth / frameWidth` 推算 |
| `startIndex` | 起始帧，`< 0` 抛异常 |
| `frameCount` | 取多少帧；`null` 表示到末尾 |
| 越界 | 任何矩形超出纹理范围都抛 `ArgumentOutOfRangeException` |

## 2. 定义 clip

```csharp
using ReluctersteSDK.Game.Rendering;

AnimationClip idle = new AnimationClip(
    name: "idle",
    sources: idleFrames,
    frameDuration: 0.25f,
    loop: true);

AnimationClip run = new AnimationClip(
    "run", runFrames, frameDuration: 0.10f, loop: true);

AnimationClip attack = new AnimationClip(
    "attack", attackFrames, frameDuration: 0.08f, loop: false);
```

需要每帧停留时长不同（关键帧多停几拍）：

```csharp
AnimationClip attack = new AnimationClip("attack", new[]
{
    new AnimationFrame(attackFrames[0], 0.06f),   // 起手很快
    new AnimationFrame(attackFrames[1], 0.20f),   // 挥砍停顿
    new AnimationFrame(attackFrames[2], 0.10f),   // 收招
}, loop: false);
```

`AnimationClip` **不可变，可共享**。把 clip 做成静态字段，所有同类实体共用一个实例：

```csharp
public static class PlayerClips
{
    public static readonly AnimationClip Idle = new("idle", idleFrames, 0.25f);
    public static readonly AnimationClip Run  = new("run",  runFrames, 0.10f);
    public static readonly AnimationClip Attack = new("attack", attackFrames, 0.08f, loop: false);
}
```

---

## 3. 挂到实体

```csharp
var animator = new Animator(PlayerClips.Idle, PlayerClips.Run, PlayerClips.Attack);

world.Add(player, animator);
world.Add(player, new Sprite(texture));

animator.Play("idle");

world.AddSystem(new SpriteAnimationSystem(), SystemPhase.Update, priority: 20);
world.AddSystem(renderSystem, SystemPhase.Render);
```

`SpriteAnimationSystem` 每帧：

```csharp
animator.Tick(deltaTime);
Rectangle? source = animator.CurrentSource;
if (source.HasValue)
    sprite.Source = source.Value;
```

它必须排在 `SpriteRenderSystem` 之前；渲染读的是 `Sprite.Source`。

## 4. 播放控制

```csharp
animator.Play("run");                  // 如果正在播 run，保持进度
animator.Play("run", restart: true);   // 强制从第 0 帧重来
animator.Pause();                      // 暂停在当前帧
animator.Resume();                     // 从暂停处继续
animator.Stop();                       // 停止并回到第一帧

animator.Speed = 2f;                   // 2 倍速；非正数/NaN/Infinity 被忽略
```

| 属性 | 含义 |
|---|---|
| `CurrentClip` | 当前 clip；从未播放为 `null` |
| `CurrentFrameIndex` | 当前帧下标 |
| `CurrentFrameTime` | 当前帧已停留秒数 |
| `IsPlaying` | 是否在推进 |
| `CurrentSource` | 当前帧矩形；无 clip 时为 `null` |
| `FinishedClip` | **本帧**刚播完的非循环 clip 名 |
| `FrameChanged` | **本帧**帧下标是否变化 |

`FinishedClip` / `FrameChanged` 在每次 `Tick` 开头被清空，只在本次推进中有效。消费它们的系统必须排在 `SpriteAnimationSystem` **之后**。

## 5. 状态切换

```csharp
public sealed class PlayerAnimationSystem : ISystem
{
    public void Execute(World world, float deltaTime)
    {
        world.Query<PlayerTag, Velocity, Animator>().ForEach(
            (Entity e, ref PlayerTag _, ref Velocity v, ref Animator animator) =>
            {
                // 攻击优先：非循环动画播完前不打断
                if (animator.CurrentClip?.Name == "attack" && animator.IsPlaying)
                    return;

                if (animator.FinishedClip == "attack")
                {
                    animator.Play("idle");
                    return;
                }

                bool moving = v.Value.SqrMagnitude > 1f;
                animator.Play(moving ? "run" : "idle");
            });
    }
}
```

要点：

- `Play` 对“正在播放的同一个 clip”默认不重置进度，可以每帧无脑调用；
- 引用相等判断：只要 clip 实例相同，就视为同一动画；
- 非循环动画播完 `IsPlaying = false`，但当前帧**停在最后一帧**，不会消失。

## 6. 攻击 / 受击等一次性动画

```csharp
public sealed class AttackSystem : ISystem
{
    public void Execute(World world, float deltaTime)
    {
        // 假设输入系统写入了 AttackRequest 组件
        world.Query<AttackRequest, Animator>().ForEach(
            (Entity e, ref AttackRequest req, ref Animator animator) =>
            {
                if (req.Triggered && animator.Play("attack", restart: true))
                    req.Triggered = false;
            });

        // FinishedClip 必须在 SpriteAnimationSystem 之后读；
        // 这里假设本系统优先级更高，则读的是上一帧的结果。
        world.Query<Animator, Health>().ForEach(
            (Entity e, ref Animator animator, ref Health health) =>
            {
                if (animator.FinishedClip == "attack")
                    Console.WriteLine("攻击动作结束");
            });
    }
}
```

如果需要在“播完的那一帧”精确处理，把消费逻辑放在一个**独立系统**，注册在 `SpriteAnimationSystem` 之后：

```csharp
world.AddSystem(new SpriteAnimationSystem(), SystemPhase.Update, priority: 20);
world.AddSystem(new AttackFinishSystem(),   SystemPhase.Update, priority: 21);
```

## 7. 完整示例

```csharp
using ReluctersteSDK.Game.Ecs;
using ReluctersteSDK.Game.Rendering;
using ReluctersteSDK.Math.Vectors;

public sealed class AnimationGame : Game
{
    // ... 省略 GraphicsDeviceManager 构造样板 ...

    private SpriteBatch _batch = null!;
    private Texture2D _sheet = null!;
    private World _world = null!;
    private Animator _animator = null!;

    protected override void LoadContent()
    {
        _batch = new SpriteBatch(GraphicsDevice);
        _sheet = LoadSheet();   // 你的 48×32 序列图

        Rectangle[] idle = SpriteSheet.Slice(_sheet, 16, 16, 3, 0, 2);
        Rectangle[] run  = SpriteSheet.Slice(_sheet, 16, 16, 3, 3, 3);
        Rectangle[] atk  = SpriteSheet.Slice(_sheet, 16, 16, 3, 6, 3);

        _world = new World();
        _animator = new Animator(
            new AnimationClip("idle", idle, 0.25f),
            new AnimationClip("run",  run,  0.10f),
            new AnimationClip("attack", atk, 0.08f, loop: false));

        Entity player = _world.Create();
        _world.Add(player, new Transform
        {
            LocalPosition = new CartesianVector2D(640, 360),
            LocalScale = new CartesianVector2D(3, 3)
        });
        _world.Add(player, new Sprite(_sheet) { Origin = new Vector2(8, 8) });
        _world.Add(player, _animator);
        _world.Add(player, new Velocity());
        _world.Add(player, new Acceleration());

        _world.AddSystem(new InputSystem(), SystemPhase.Update, -100);
        _world.AddSystem(new MotionSystem(), SystemPhase.Update, -10);
        _world.AddSystem(new TransformSystem(), SystemPhase.Update, 10);
        _world.AddSystem(new SpriteAnimationSystem(), SystemPhase.Update, 20);
        _world.AddSystem(new PlayerAnimationSystem(), SystemPhase.Update, 21);

        var render = new SpriteRenderSystem();
        _world.AddSystem(render, SystemPhase.Render);

        _animator.Play("idle");
    }

    protected override void Update(GameTime gameTime)
    {
        _world.Update((float)gameTime.ElapsedGameTime.TotalSeconds);
        base.Update(gameTime);
    }
}
```

## 8. 限制与陷阱

| 限制 | 说明 |
|---|---|
| 只有矩形采样 | 不支持旋转、描点、网格形变 |
| 一个实体一个 `Animator` | 上下半身各播一套请拆成父子实体 |
| 没有帧事件 | 用 `FrameChanged` + `CurrentFrameIndex` 轮询 |
| 没有过渡/混合 | `Play` 是硬切 |
| 不支持倒放 | `Speed` 负数被忽略 |
| clip 名区分大小写 | `"Run"` 与 `"run"` 不同 |
| `FrameChanged` 在 `Play` 时置位 | 切动画那一帧也会收到“变了” |
| 极长 `deltaTime` | `Tick` 单次最多推进 10000 帧，防止死循环 |
