# 03 · 查询与迭代安全

**目标**：一次遍历多个组件、排除特定实体、统计数量，并理解“遍历中改结构”为什么必须走命令缓冲或快照。

---

## 1. 单组件查询

```csharp
world.Query<Health>().ForEach((Entity e, ref Health h) =>
{
    h.Value -= 1;
});
```

`ForEach` 的参数是 **`ref` 委托**：组件以引用传入，回调里直接改就是改存储。

```csharp
public delegate void RefAction<T1>(Entity entity, ref T1 c1) where T1 : notnull;
```

C# 元组不能带 `ref`，所以查询不使用 `foreach`，而是回调。

---

## 2. 双 / 三 / 四组件交集

```csharp
// 同时持有 Transform 与 Velocity
world.Query<Transform, Velocity>().ForEach((Entity e, ref Transform t, ref Velocity v) =>
{
    t.LocalPosition += v.Value * 0.016f;
});

// 三组件
world.Query<Transform, Velocity, Health>().ForEach(
    (Entity e, ref Transform t, ref Velocity v, ref Health h) =>
    {
        if (h.Value <= 0)
            v.Value = CartesianVector2D.Zero;
    });

// 四组件
world.Query<Transform, Velocity, Health, Team>().ForEach(
    (Entity e, ref Transform t, ref Velocity v, ref Health h, ref Team team) =>
    {
        // ...
    });
```

实现上是**交集**：选 `Count` 最小的存储作为驱动，其余用 `TryGetDense` 做 O(1) 判断。两个存储数量悬殊时仍然接近线性。

---

## 3. 排除查询 `Without`

```csharp
// 有 Health、但没有 Dead 的实体
world.Query<Health>().Without<Dead>().ForEach((Entity e, ref Health h) =>
{
    h.Value -= 1;
});

// 链式排除多个
world.Query<Transform, Sprite>()
    .Without<Hidden>()
    .Without<Destroyed>();
```

`Without<T>()` 返回一个新的查询结构体，可以继续链式调用。它只做“必须不持有”，没有 `Any<T>` / `OneOf<T>` 语义。

---

## 4. 数量与快照

```csharp
int alive = world.Query<Health>().Count;                    // 每次调用现算
int aliveVisible = world.Query<Health>().Without<Hidden>().Count;

Entity[] snapshot = world.Query<Health>().ToEntityArray();
```

`Count` 不是缓存值，遍历成本与实体数成正比。需要多次使用就先存下来。

---

## 5. 迭代安全：为什么遍历中不能改结构

`Query.ForEach` 在每次回调**前后**校验 `StructuralVersion`：

```csharp
world.Query<Health>().ForEach((Entity e, ref Health h) =>
{
    if (h.Value <= 0)
        world.Destroy(e);      // ❌ 立即抛 InvalidOperationException
});
```

抛出的信息会提示两条合法路径。

### 路径一：命令缓冲（推荐）

```csharp
world.Query<Health>().ForEach((Entity e, ref Health h) =>
{
    if (h.Value <= 0)
        world.Commands.Destroy(e);   // 只是登记，不立刻改结构
});

world.Update(dt);   // 每个系统执行后自动回放
```

命令缓冲把修改推迟到安全时机，执行顺序确定。完整用法见 [10-命令缓冲.md](10-命令缓冲.md)。

### 路径二：先取实体快照

```csharp
foreach (Entity e in world.Query<Health>().ToEntityArray())
{
    if (!world.IsAlive(e))
        continue;

    if (world.Get<Health>(e).Value <= 0)
        world.Destroy(e);            // ✅ 不在 ForEach 回调里
}
```

`ToEntityArray()` 会分配一次数组，但换来了“遍历数组、随意改世界”的自由。记得每次访问前用 `IsAlive` 兜底——销毁可能来自更早的迭代。

---

## 6. 哪些操作算“结构修改”

| 操作 | 自增 `StructuralVersion` |
|---|---|
| `Create()` / `Destroy()` | ✅ |
| `Add<T>`（新建） | ✅ |
| `Add<T>`（覆盖） | ❌ |
| `Remove<T>`（确实移除） | ✅ |
| `SetSingleton`（新建） | ✅ |
| `SetSingleton`（覆盖） | ❌ |
| `SetParent` / `RemoveParent` | **新建** `Parent` / `Children` 组件时 ✅；只是改已有父引用时 ❌。两者都会自增 `HierarchyVersion` |
| `WorldTransform` 被 `TransformSystem` 覆盖 | ❌（第一次创建时 ✅） |

所以：

- 遍历中修改组件字段是安全的；
- **第一次** `SetParent`（给实体新增 `Parent`、给父节点新增 `Children`）是结构修改，可能抛异常；换父（`Parent` 已存在）通常安全；
- 增删实体/组件一律走命令缓冲。

---

## 7. 热路径写法

`ForEach` 每次回调都有一次委托间接调用。极热路径可以直接遍历存储：

```csharp
ComponentStore<Health> healths = world.Store<Health>();
Span<Health> values = healths.Components;

for (int i = 0; i < values.Length; i++)
    values[i].Value -= 1;
```

需要同时访问两个存储时，用 `TryGetDense` 自己求交集：

```csharp
ComponentStore<Health> healths = world.Store<Health>();
ComponentStore<Attack> attacks = world.Store<Attack>();

ReadOnlySpan<Entity> entities = healths.Entities;
Span<Health> hs = healths.Components;
Span<Attack> ats = attacks.Components;

for (int i = 0; i < entities.Length; i++)
{
    if (!attacks.TryGetDense(entities[i].Index, out int dense))
        continue;

    hs[i].Value -= ats[dense].Damage;
}
```

> 这条路径绕过了 `StructuralVersion` 校验，**只适合只读或只改字段**的循环。

## 8. 完整示例：每帧结算伤害

```csharp
public struct Health { public int Value; public int Max; }
public struct DamageOverTime { public int PerSecond; }
public struct Dead { }

public sealed class DotSystem : ISystem
{
    public void Execute(World world, float dt)
    {
        world.Query<Health, DamageOverTime>()
            .Without<Dead>()
            .ForEach((Entity e, ref Health h, ref DamageOverTime dot) =>
            {
                h.Value -= Math.Max(1, (int)(dot.PerSecond * dt));

                if (h.Value <= 0)
                    world.Commands.Add(e, new Dead());   // 标记死亡，结构修改延后
            });
    }
}
```

`Dead` 是空结构体，只用它的“存在”表示状态。查询里用 `Without<Dead>` 排除已经死亡的实体。
