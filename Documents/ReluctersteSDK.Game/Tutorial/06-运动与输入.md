# 06 · 运动与输入

**目标**：用 `Velocity` / `Acceleration` / `Damping` / `Heading` 做一个“按键加速、松手减速、限速”的玩家控制器，并知道阻尼参数怎么调不会炸。

---

## 1. `MotionSystem` 每帧做什么

对每个同时持有 `Transform` 与 `Velocity` 的实体：

```
a = Has<Acceleration> ? Acceleration.Value : Zero

若 Has<Damping> 且 Coefficient > 0:
    若 |v|² < 1e-12 → v = 0          （防止方向抖动）
    v += (a - k·v) · dt               （一阶阻尼）
    若 MaxSpeed > 0 且 |v| > MaxSpeed → v = 归一化(v) · MaxSpeed
否则:
    v += a · dt

position += v · dt                    （用更新后的速度）

若 Has<Heading> 且 v ≠ 0:
    Heading.Radians = Atan2(v.Y, v.X)
```

`Transform` 与 `Velocity` 是必需组件；`Acceleration` / `Damping` / `Heading` 都可选。

---

## 2. 组件字段

```csharp
public struct Velocity     { public CartesianVector2D Value; }   // 单位/秒
public struct Acceleration { public CartesianVector2D Value; }   // 单位/秒²
public struct Damping      { public float Coefficient; public float MaxSpeed; }
public struct Heading      { public float Radians; }
```

| 字段 | 零值语义 |
|---|---|
| `Damping.Coefficient <= 0` | **无阻尼**（`default(Damping)` 是彻底的空操作） |
| `Damping.MaxSpeed <= 0` | **不限速** |
| 没有 `Acceleration` | 加速度视为 0 |
| 没有 `Heading` | 不维护朝向 |

> 加了 `new Damping()` 却没设 `Coefficient`，等于没加。这是最常见的“为什么没减速”。

## 3. 键盘控制器

```csharp
using Microsoft.Xna.Framework.Input;
using ReluctersteSDK.Game.Ecs;
using ReluctersteSDK.Math.Vectors;

public struct PlayerTag { }

public sealed class InputSystem : ISystem
{
    public void Execute(World world, float deltaTime)
    {
        KeyboardState kb = Keyboard.GetState();

        CartesianVector2D direction = CartesianVector2D.Zero;
        if (kb.IsKeyDown(Keys.A)) direction += new CartesianVector2D(-1, 0);
        if (kb.IsKeyDown(Keys.D)) direction += new CartesianVector2D(1, 0);
        if (kb.IsKeyDown(Keys.W)) direction += new CartesianVector2D(0, -1);
        if (kb.IsKeyDown(Keys.S)) direction += new CartesianVector2D(0, 1);

        if (direction.SqrMagnitude > 0f)
            direction = direction.Normalized;

        world.Query<PlayerTag, Acceleration>().ForEach(
            (Entity e, ref PlayerTag _, ref Acceleration accel) =>
                accel.Value = direction * 900f);
    }
}
```

注意 **每帧都要重写 `Acceleration.Value`**：组件是持久数据，不清零就会一直加速。

## 4. 玩家实体

```csharp
Entity player = world.Create();

world.Add(player, new Transform
{
    LocalPosition = new CartesianVector2D(640, 360),
    LocalScale = new CartesianVector2D(24, 24)
});

world.Add(player, new PlayerTag());
world.Add(player, new Velocity());
world.Add(player, new Acceleration());
world.Add(player, new Damping
{
    Coefficient = 6f,
    MaxSpeed = 240f
});
world.Add(player, new Heading());

world.AddSystem(new InputSystem(),    SystemPhase.Update, priority: -100);
world.AddSystem(new MotionSystem(),   SystemPhase.Update, priority: -10);
world.AddSystem(new TransformSystem(),SystemPhase.Update, priority: 10);
```

行为：

- 按下 D：加速度 +900，速度逐渐上升，最高 240；
- 松开：加速度归零，`-k·v` 把速度拉回 0；
- `Heading` 在移动时自动指向速度方向。

---

## 5. 阻尼参数怎么调

公式：`v' = v + (a − k·v)·dt`，显式欧拉。

稳定条件大致是：

```
k · dt < 2
```

| 参数 | 效果 | 风险 |
|---|---|---|
| `k = 6`, `dt = 1/60` | 约 0.4 秒停下，手感干脆 | 安全 |
| `k = 20`, `dt = 1/60` | 很快停下 | 安全但偏硬 |
| `k = 500`, `dt = 0.05` | 强烈振荡 | `k·dt = 25`，可能发散 |
| `k = 6`, `dt = 0.5` | 一帧走半秒 | 数值上仍稳定，但位移会跳 |

高阻尼 + 低帧率时，考虑：

- 给 `dt` 设上限（例如 `Math.Min(dt, 1f / 30f)`）；
- 或改用固定步长更新（把 `world.Update` 放进累加器循环）。

## 6. 瞬移与冲刺：直接写速度

`MotionSystem` 只负责积分，不阻止你直接改速度：

```csharp
// 冲刺：瞬间把速度设为 600
world.Get<Velocity>(player).Value = new CartesianVector2D(600, 0);

// 传送：改位置并清速度
ref Transform t = ref world.Get<Transform>(player);
t.LocalPosition = new CartesianVector2D(100, 100);
t.IsDirty = true;
world.Get<Velocity>(player).Value = CartesianVector2D.Zero;
```

`t.IsDirty = true` 让 `TransformSystem` 下一帧重算；即使不置位，快照比对也能发现变化，但显式置位更省一次比较。

## 7. 没有 `MotionSystem` 的纯手写运动

不想用内置系统时，自己写：

```csharp
public sealed class MyMotionSystem : ISystem
{
    public void Execute(World world, float deltaTime)
    {
        world.Query<Transform, Velocity>().ForEach(
            (Entity e, ref Transform t, ref Velocity v) =>
            {
                t.LocalPosition += v.Value * deltaTime;
                t.IsDirty = true;
            });
    }
}
```

适合需要特殊积分（例如平台跳跃、分段变速）的场景。记得把 `TransformSystem` 排在它后面。

---

## 8. 朝向限制

- `MotionSystem` **不处理角速度**：没有 `AngularVelocity` / `AngularAcceleration`；
- `Heading` 只在速度非零时更新，停下后保持最后朝向；
- 需要“永远面向鼠标”，自己写一个系统：

```csharp
public sealed class AimAtMouseSystem : ISystem
{
    public void Execute(World world, float deltaTime)
    {
        MouseState mouse = Mouse.GetState();

        world.Query<PlayerTag, Transform, Heading>().ForEach(
            (Entity e, ref PlayerTag _, ref Transform t, ref Heading h) =>
            {
                CartesianVector2D delta = new CartesianVector2D(
                    mouse.X - t.LocalPosition.X,
                    mouse.Y - t.LocalPosition.Y);

                if (delta.SqrMagnitude > 0f)
                    h.Radians = MathF.Atan2(delta.Y, delta.X);
            });
    }
}
```
