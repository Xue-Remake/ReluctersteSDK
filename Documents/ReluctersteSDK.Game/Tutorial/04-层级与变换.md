# 04 · 层级与变换

**目标**：让武器跟着角色、让 UI 跟着摄像机锚点，并理解局部变换如何累乘成世界变换。

---

## 1. Transform 只存局部值

```csharp
using ReluctersteSDK.Game.Ecs;
using ReluctersteSDK.Math.Vectors;

Entity body = world.Create();
world.Add(body, new Transform
{
    LocalPosition = new CartesianVector2D(400, 300),
    LocalRotation = 0f,
    LocalScale = CartesianVector2D.One
});
```

| 字段 | 含义 |
|---|---|
| `LocalPosition` | 相对父节点的位置 |
| `LocalRotation` | 相对父节点的旋转（弧度，正值逆时针） |
| `LocalScale` | 相对父节点的缩放 |
| `IsDirty` | 提示 `TransformSystem` 重算 |

**新实体务必用 `Transform.Identity`**：

```csharp
world.Add(e, Transform.Identity);   // ✅ 缩放为 (1,1)
world.Add(e, new Transform());      // ⚠️ default：缩放为 (0,0)
```

`ToMatrix()` 会把零缩放按 `(1,1)` 处理，所以 `default(Transform)` 不会让物体消失，但它仍然不等于 `Identity`——别依赖这个兜底。

## 2. 建立父子关系

```csharp
Entity body = world.Create();
world.Add(body, Transform.Identity);

Entity sword = world.Create();
world.Add(sword, new Transform
{
    LocalPosition = new CartesianVector2D(16, 4),
    LocalRotation = 0f,
    LocalScale = CartesianVector2D.One
});

bool ok = world.SetParent(sword, body);   // true
```

`SetParent` 会同时维护两侧：

- 写入 `sword.Parent = body`；
- 把 `sword` 追加到 `body.Children.Items`；
- 自动从旧父节点摘除（换父）；
- 把 `sword` 的 `Transform.IsDirty` 置为 `true`。

以下情况返回 `false`，不改变层级：

| 情况 | 返回值 |
|---|---|
| 子或父已失效 | `false` |
| `child == parent`（自环） | `false` |
| `parent` 的祖先链里已经包含 `child`（成环） | `false` |

### 查询关系

```csharp
Entity parent = world.GetParent(sword);          // body；无父返回 Entity.Null
IReadOnlyList<Entity> kids = world.GetChildren(body);
bool isAncestor = world.IsInAncestorChain(sword, body);   // true

world.RemoveParent(sword);                        // 升级为根
```

**不要手工改 `Children.Items`**：它是只读视图。所有层级修改都走 `SetParent` / `RemoveParent` / `Destroy`。

### 销毁父节点

```csharp
world.Destroy(body);
```

- `body` 的所有组件被清理；
- 子节点**不会**被销毁，而是移除 `Parent`、升级为根；
- 子节点的 `Transform.IsDirty` 会被置位，下一帧按“根”重新计算世界矩阵。

单父约束：一个实体只能有一个父。`Children` 的顺序是“最后挂上的在最后”，不要依赖它做稳定排序。

## 3. 注册 TransformSystem

```csharp
world.AddSystem(new MotionSystem(), SystemPhase.Update, priority: -10);
world.AddSystem(new TransformSystem(), SystemPhase.Update, priority: 10);
```

`TransformSystem` 每帧：

1. 收集“没有可用父节点”的实体作为根；
2. DFS 生成**父先于子**的拓扑序；
3. 只重算需要更新的实体（脏标记、快照变化、缺 `WorldTransform`、父节点本帧重算）；
4. 写入：

```csharp
local = Transform.ToMatrix();
if (父有 WorldTransform)
    local = local * parentWorld;      // 行向量：子在前、父在后

world.Add(entity, new WorldTransform { Value = local });
```

### 顺序约束

`TransformSystem` **必须排在所有修改 `LocalPosition` / `LocalRotation` / `LocalScale` 的系统之后**。否则你算的是上一帧的局部值。

推荐：

```
输入/AI → MotionSystem(-10) → 游戏逻辑 → TransformSystem(10) → 动画 → 渲染
```

### 没有 TransformSystem 会怎样

渲染系统优先读 `WorldTransform`；没有时退回 `transform.ToMatrix()`。所以：

- 扁平场景可以不注册 `TransformSystem`；
- 只要用了 `SetParent`，就**必须**注册，否则子物体的世界矩阵不会跟随父节点。

### 手动强制全量重算

```csharp
var transformSystem = new TransformSystem();
world.AddSystem(transformSystem, SystemPhase.Update, priority: 10);

// 例如从存档恢复、批量传送之后
transformSystem.FullRebuild();
```

## 4. 读取世界位置

```csharp
using System.Numerics;
using ReluctersteSDK.Math.Matrices;
using ReluctersteSDK.Math.Vectors;

if (world.TryGet<WorldTransform>(sword, out WorldTransform wt))
{
    CartesianVector2D worldPos = wt.Value.TransformPoint(CartesianVector2D.Zero);
    Console.WriteLine($"剑在世界坐标 {worldPos.X}, {worldPos.Y}");
}
```

也可以直接取矩阵的平移分量：

```csharp
Matrix3x2 m = wt.Value;
var position = new CartesianVector2D(m.M31, m.M32);
```

> `Matrix3x2` 是 `System.Numerics` 的类型；`Transform2DMath.Decompose` 与 `TransformPoint` 扩展来自 `ReluctersteSDK.Math.Matrices`。

## 5. 完整示例：角色与武器

```csharp
using ReluctersteSDK.Game.Ecs;
using ReluctersteSDK.Game.Systems;
using ReluctersteSDK.Math.Vectors;

var world = new World();
world.AddSystem(new TransformSystem(), SystemPhase.Update, priority: 10);

// 角色
Entity body = world.Create();
world.Add(body, new Transform
{
    LocalPosition = new CartesianVector2D(400, 300),
    LocalScale = CartesianVector2D.One
});

// 武器：相对角色偏移 (16, 4)
Entity sword = world.Create();
world.Add(sword, new Transform
{
    LocalPosition = new CartesianVector2D(16, 4),
    LocalScale = CartesianVector2D.One
});

world.SetParent(sword, body);

world.Update(0.016f);   // 触发 TransformSystem

WorldTransform swordWorld = world.Get<WorldTransform>(sword);
CartesianVector2D pos = swordWorld.Value.TransformPoint(CartesianVector2D.Zero);
Console.WriteLine(pos.X);   // 416
Console.WriteLine(pos.Y);   // 304

// 角色旋转 90°，武器跟着转
world.Get<Transform>(body).LocalRotation = MathF.PI / 2f;
world.Get<Transform>(body).IsDirty = true;
world.Update(0.016f);

pos = world.Get<WorldTransform>(sword).Value.TransformPoint(CartesianVector2D.Zero);
// 偏移 (16,4) 被旋转后约 (-4, 16)，再加角色位置
```

## 6. 常见陷阱

| 现象 | 原因 |
|---|---|
| 子物体不跟随 | 没注册 `TransformSystem`，或它排在修改位置的系统之前 |
| 子物体抖动一帧 | 先渲染后 `Update`；把 `world.Update` 放在 `Draw` 之前 |
| 改 `LocalPosition` 后世界矩阵不变 | 修改发生在 `TransformSystem` 之后；调整优先级或下一帧才生效 |
| `SetParent` 返回 `false` | 实体失效、自环或成环；用 `world.IsAlive` 与 `IsInAncestorChain` 排查 |
| 子物体缩放为 0 | 用了 `default(Transform)`；改成 `Transform.Identity` |
