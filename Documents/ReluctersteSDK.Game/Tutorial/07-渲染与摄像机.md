# 07 · 渲染与摄像机

**目标**：把实体画到屏幕上，控制层序与锚点，用 `Camera2D` 跟随玩家，并做屏幕坐标拾取。

---

## 1. Sprite 是组件

```csharp
using Microsoft.Xna.Framework;
using Microsoft.Xna.Framework.Graphics;
using ReluctersteSDK.Game.Rendering;

var sprite = new Sprite(texture)
{
    Source = new Rectangle(0, 0, 32, 32),   // 默认整张纹理
    Tint = Color.White,                      // 默认白色
    Layer = 10,                              // 数值小的先画（在下面）
    Depth = 0f,                              // 同层内数值小的先画
    Origin = new Vector2(16, 16),            // 锚点（纹理像素空间）
    Effects = SpriteEffects.None
};

world.Add(player, sprite);
```

`Sprite` 是 **class**，不是 struct：`Color` 的 `default` 是透明黑，struct 忘记设 `Tint` 会让精灵完全不可见。

| 字段 | 作用 |
|---|---|
| `Texture` | 纹理；为 `null` 时渲染系统跳过 |
| `Source` | 采样矩形；序列图动画用它切帧 |
| `Tint` | 乘法着色；做受击闪白、半透明都用它 |
| `Layer` | 层号，升序先画 |
| `Depth` | 同层深度，升序先画；最终传给 `SpriteBatch.Draw` |
| `Origin` | 旋转/缩放中心，默认左上角 |
| `Effects` | `FlipHorizontally` / `FlipVertically` |

## 2. 注册渲染系统

```csharp
var renderSystem = new SpriteRenderSystem();
world.AddSystem(renderSystem, SystemPhase.Render);
```

`Draw` 里：

```csharp
protected override void Draw(GameTime gameTime)
{
    GraphicsDevice.Clear(Color.CornflowerBlue);

    float dt = (float)gameTime.ElapsedGameTime.TotalSeconds;
    world.Render(dt);        // Execute：收集 (Transform, Sprite) 实体

    _spriteBatch.Begin(
        sortMode: SpriteSortMode.Deferred,       // 必须
        samplerState: SamplerState.PointClamp,
        blendState: BlendState.AlphaBlend);

    renderSystem.Submit(_spriteBatch);           // 排序 + Draw

    _spriteBatch.End();

    base.Draw(gameTime);
}
```

**`Begin` 必须是 `SpriteSortMode.Deferred`**。`Submit` 已经在托管侧按 Layer → Depth → 纹理 → 实体索引排好序；换成 `Texture` / `BackToFront` 等模式，SpriteBatch 会再排一次，层序被破坏。

### 排序规则

```
Layer 升序 → Depth 升序 → 纹理（RuntimeHelpers.GetHashCode）→ EntityIndex
```

- 前两层决定视觉遮挡；
- 第三层把同纹理的绘制命令聚在一起，减少合批中断；
- 第四层保证完全相同的键下顺序稳定，帧间不闪烁。

## 3. 矩阵来源

每个实体：

```csharp
Matrix3x2 m = world.TryGet<WorldTransform>(e, out var wt)
    ? wt.Value
    : transform.ToMatrix();
```

- 注册了 `TransformSystem`：用累乘后的世界矩阵；
- 没注册：用局部矩阵（扁平场景）。
- 设置 `Camera` 后：再乘 `ViewMatrix`，输出屏幕坐标。

`renderSystem.Commands` 是上一帧收集到的 `RenderCommand` 列表，可用于调试或二次处理（`Submit` 后会被排序）。

### Math 向量与 MonoGame 向量

```csharp
using ReluctersteSDK.Game.Rendering;
using ReluctersteSDK.Math.Vectors;

Microsoft.Xna.Framework.Vector2 xna = new(10, 20);
CartesianVector2D mathVector = xna.ToCartesian();
Microsoft.Xna.Framework.Vector2 back = mathVector.ToXna();
```

两者不会隐式转换；在既算 `Transform` 又调 `SpriteBatch.Draw` 的文件里，显式调用 `ToXna()` / `ToCartesian()`。

## 4. 摄像机

```csharp
var camera = new Camera2D
{
    Position = new CartesianVector2D(640, 360),   // 摄像机中心的世界坐标
    Rotation = 0f,
    Zoom = 1f
};

camera.Resize(GraphicsDevice.Viewport.Width, GraphicsDevice.Viewport.Height);

renderSystem.Camera = camera;
renderSystem.CullingEnabled = true;     // 默认 true
```

| 成员 | 说明 |
|---|---|
| `Position` | 摄像机中心 |
| `Rotation` | 弧度，正值逆时针 |
| `Zoom` | 必须 > 0；非法值被忽略 |
| `ViewMatrix` | 世界 → 屏幕 |
| `ViewBounds` | 当前可见世界 AABB |
| `WorldToScreen` / `ScreenToWorld` | 单点转换 |
| `Resize(w, h)` | 同步视口 |

窗口尺寸变化时记得同步（在 `Update` 里检测视口变化即可）：

```csharp
if (camera.ViewportWidth != GraphicsDevice.Viewport.Width ||
    camera.ViewportHeight != GraphicsDevice.Viewport.Height)
{
    camera.Resize(GraphicsDevice.Viewport.Width, GraphicsDevice.Viewport.Height);
}
```

### 摄像机跟随

放在 LateUpdate，保证读到的世界矩阵是本帧最终值：

```csharp
public sealed class CameraFollowSystem : ISystem
{
    private readonly Camera2D _camera;

    public CameraFollowSystem(Camera2D camera) => _camera = camera;

    public void Execute(World world, float deltaTime)
    {
        world.Query<PlayerTag, WorldTransform>().ForEach(
            (Entity e, ref PlayerTag _, ref WorldTransform wt) =>
                _camera.Position = new CartesianVector2D(wt.Value.M31, wt.Value.M32));
    }
}

world.AddSystem(new CameraFollowSystem(camera), SystemPhase.LateUpdate);
```

需要平滑跟随：

```csharp
CartesianVector2D target = new CartesianVector2D(wt.Value.M31, wt.Value.M32);
_camera.Position = CartesianVector2D.Lerp(
    _camera.Position, target, 1f - MathF.Exp(-8f * deltaTime));
```

（`Lerp` 是 `CartesianVector2D` 的成员，`t` 会被 clamp 到 `[0,1]`。）

## 5. 裁剪

```csharp
renderSystem.Camera = camera;
renderSystem.CullingEnabled = true;
```

每帧：

```csharp
Console.WriteLine($"本帧裁剪 {renderSystem.LastCulledCount} 个精灵");
```

裁剪是**保守 AABB**：把 sprite 四角变换到世界空间求包围盒，与 `camera.ViewBounds` 相交。旋转的 sprite 包围盒会偏大，但不会误删。没有空间分区，实体很多时裁剪本身仍要遍历所有 sprite。

## 6. 屏幕坐标拾取

```csharp
MouseState mouse = Mouse.GetState();

CartesianVector2D worldPoint = camera.ScreenToWorld(
    new CartesianVector2D(mouse.X, mouse.Y));

world.Query<Transform, Sprite>().ForEach((Entity e, ref Transform t, ref Sprite s) =>
{
    // 简单圆/矩形拾取，按需换成 Aabb2D / Circle2D
    float dx = worldPoint.X - t.LocalPosition.X;
    float dy = worldPoint.Y - t.LocalPosition.Y;
    if (dx * dx + dy * dy < 32 * 32)
        Console.WriteLine($"点中了 {e}");
});
```

`Camera2D` 本身不做拾取；`ReluctersteSDK.Math.Geometry` 提供 `Aabb2D` / `Circle2D` / `Ray2D` / `Polygon2D`，可以配合使用：

```csharp
using ReluctersteSDK.Math.Geometry;

var bounds = new Aabb2D(0, 0, 32, 32);
bool hit = bounds.Contains(worldPoint);
```

## 7. 完整示例：跟随玩家的摄像机

```csharp
using Microsoft.Xna.Framework;
using Microsoft.Xna.Framework.Graphics;
using ReluctersteSDK.Game.Ecs;
using ReluctersteSDK.Game.Rendering;
using ReluctersteSDK.Game.Systems;
using ReluctersteSDK.Math.Vectors;

public sealed class SceneGame : Game
{
    private readonly GraphicsDeviceManager _graphics;
    private SpriteBatch _batch = null!;
    private Texture2D _tex = null!;
    private World _world = null!;
    private SpriteRenderSystem _render = null!;
    private Camera2D _camera = null!;
    private Entity _player;

    public SceneGame()
    {
        _graphics = new GraphicsDeviceManager(this)
        {
            PreferredBackBufferWidth = 1280,
            PreferredBackBufferHeight = 720
        };
    }

    protected override void LoadContent()
    {
        _batch = new SpriteBatch(GraphicsDevice);

        _tex = new Texture2D(GraphicsDevice, 32, 32);
        Color[] pixels = new Color[32 * 32];
        Array.Fill(pixels, Color.Orange);
        _tex.SetData(pixels);

        _world = new World();
        _render = new SpriteRenderSystem();
        _camera = new Camera2D
        {
            Position = new CartesianVector2D(640, 360),
            Zoom = 1.5f
        };
        _camera.Resize(GraphicsDevice.Viewport.Width, GraphicsDevice.Viewport.Height);
        _render.Camera = _camera;

        _world.AddSystem(new InputSystem(), SystemPhase.Update, -100);
        _world.AddSystem(new MotionSystem(), SystemPhase.Update, -10);
        _world.AddSystem(new TransformSystem(), SystemPhase.Update, 10);
        _world.AddSystem(new CameraFollowSystem(_camera), SystemPhase.LateUpdate);
        _world.AddSystem(_render, SystemPhase.Render);

        _player = _world.Create();
        _world.Add(_player, new Transform
        {
            LocalPosition = new CartesianVector2D(640, 360),
            LocalScale = new CartesianVector2D(2, 2)   // 32×32 纹理 → 64×64
        });
        _world.Add(_player, new PlayerTag());
        _world.Add(_player, new Velocity());
        _world.Add(_player, new Acceleration());
        _world.Add(_player, new Damping { Coefficient = 6f, MaxSpeed = 300f });
        _world.Add(_player, new Sprite(_tex) { Origin = new Vector2(16, 16) });
    }

    protected override void Update(GameTime gameTime)
    {
        _world.Update((float)gameTime.ElapsedGameTime.TotalSeconds);
        base.Update(gameTime);
    }

    protected override void Draw(GameTime gameTime)
    {
        GraphicsDevice.Clear(new Color(20, 24, 30));

        _world.Render((float)gameTime.ElapsedGameTime.TotalSeconds);

        _batch.Begin(sortMode: SpriteSortMode.Deferred, samplerState: SamplerState.PointClamp);
        _render.Submit(_batch);
        _batch.End();

        base.Draw(gameTime);
    }

    protected override void UnloadContent()
    {
        _world.Dispose();
        _tex.Dispose();
        _batch.Dispose();
        base.UnloadContent();
    }
}
```

（`InputSystem` / `CameraFollowSystem` / `PlayerTag` 来自 [06-运动与输入.md](06-运动与输入.md) 与本章。）

## 8. 常见问题

| 现象 | 原因 |
|---|---|
| 精灵不可见 | `Tint` 被设成透明；`Texture` 为 null；`LocalScale` 为 0 |
| 层序错乱 | `Begin` 不是 `Deferred` |
| 锚点不对 | `Origin` 默认左上角；居中要 `new Vector2(w/2f, h/2f)` |
| 摄像机里一片空白 | 忘记给 `renderSystem.Camera` 赋值，或 `Zoom` 非法被忽略 |
| 拾取偏移 | 忘了 `ScreenToWorld`，直接用鼠标像素当世界坐标 |
| 翻转后位置偏 | 负缩放分解会丢失；用 `SpriteEffects.FlipHorizontally` |
